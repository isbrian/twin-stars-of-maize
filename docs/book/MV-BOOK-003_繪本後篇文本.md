## 寫法（Brian 2026-10-07 決定）

沿用前篇的語氣（繪本口吻短句、關鍵句保留原典對句節奏）與出處標注方式；以下是後篇不同或新增的決定。

| 項目 | 決定 |
|---|---|
| 讀者 | 通關後的玩家；可以劇透 |
| 範圍 | 完整原典故事，從貓頭鷹使者的召喚到升天 |
| 改編標示 | 正文只講原典；有改編的那張，正文下方另加一小段「遊戲裡」，排版用較小字體 |
| 字數 | 正文每張 80～150 字；「遊戲裡」另計，最多 50 字 |
| 順序 | 照 ART_SPEC 的 20 張（遊戲順序）；第 10 張的「遊戲裡」說明原典把 Seven Macaw 父子講在父輩之前 |
| 死亡場面 | 照實說發生了什麼（砍頭、取出心臟），不寫血與身體細節（例如斷四肢、心臟放在葉子上） |
| 獻祭一個人 | 第 19 張正文照原典寫；省略理由寫在該張「遊戲裡」，說明是尊重而不是迴避 |
| 祖母與哥哥 | 照原典寫祖母起初不疼愛雙胞胎、哥哥嫉妒欺負他們，語氣溫和；「遊戲裡」說明遊戲中祖母一開始就溫暖 |
| 諸王點名 | 第 14 張照原典列出蚊子叫出的 12 個名字（含血牙、血爪，不含掃穢魔、突刺魔）；其餘依情節點名 |
| 英文版 | 繁中定稿後另立工單 MV-BOOK-004 |
