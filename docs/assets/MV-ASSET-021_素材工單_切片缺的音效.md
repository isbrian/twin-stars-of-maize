## 全部音效共通的限制

聲音語彙是這部作品的核心（AUDIO_SPEC 第 2 節），**本批任何音效都不可以像語彙**，否則玩家會誤判：

| 不可以 | 因為那是 |
|---|---|
| 音高往上爬的短句 | 前兆（可招架＝短促上揚） |
| 結尾一記低沉單音的「咚」（40～150 Hz 的重擊） | 不可招架前兆的結尾 |
| 持續的低頻平穩嗡聲 | 危險 |
| 乾、短、空洞的敲擊＋回聲 | 虛假（**例外**：A21-7 下劈水晶、G4 假光造物本來就屬虛假類） |
| 一下敲擊後持續約 1.5 秒的清楚音高鳴響 | 真實 |
| 規律、等距的脈動 | 活物 |
| 從無聲漸強到驟停的倒轉氣音 | 殘響 |

其他共通限制：不可使用馬林巴、吉他、弦樂、西式合唱、泛用部落風鼓組；不可有任何語言的人聲或唱詞、不可有人的呻吟或喊叫；不模仿特定儀式音樂或聖歌。

技術規格（AUDIO_SPEC 第 8 節）：WAV，48 kHz／16-bit，單聲道；峰值不超過 -1 dBTP；檔名 `sfx_{類別}_{描述}_{變體兩位數}.wav`。響度目標（整合響度）：

| 類別 | 目標 |
|---|---|
| 腳步 | 約 -28 LUFS |
| 移動（跳、落地、翻滾）、介面 | 約 -26 LUFS |
| 武器、戰鬥、敵人、能力與拾取 | 約 -20 LUFS |
| 過場 | 約 -22 LUFS |
