## 本批的設計決定

| 項目 | 決定 | 理由 |
|---|---|---|
| 各招的前兆 | **沿用第 0 批的 `sfx_voc_tell_parry_*`（可招架）與 `sfx_voc_tell_heavy_*`（不可招架）**，不為 Seven Macaw 另做 | 前兆是全作共用的語彙；MV-PROTO-005 學過之後前兆↔危險誤判 0／72，換一套新的反而要重學 |
| Seven Macaw 的整體音色 | 薄金屬、玻璃、珠寶相碰：亮而空，**幾乎沒有低頻** | 「華麗而空洞」屬虛假類（BOSS-001 第 7 節）；MUS-B01 也刻意缺少低頻 |
| 招式本體不可像語彙 | 每則都列出要避開的類別：不上揚（前兆）、不持續低鳴（危險）、不倒轉氣音（殘響）、不規律脈動（活物） | 招式聲和前兆同時出現，像語彙就會讓玩家誤判 |
| 俯衝、落地 | 破風聲**音高往下降**，落地是鬆土與羽毛的撲擊，**不可有低沉單音的「咚」** | 不可招架前兆的結尾就是一記低沉重擊（AUDIO_SPEC 第 2 節） |
| 響度 | 音效約 -20 LUFS（與第 0 批相同）；光束蓄力約 -26 LUFS；環境層約 -30 LUFS；配樂約 -18 LUFS；峰值都不超過 -1 dBTP | 光束蓄力和不可招架前兆同時播放，要讓前兆在上面（第 7 節混音優先級 1） |
| 不做 | 吹箭射中微亮（沿用通用「命中弱點」）；召喚（沿用展翅聚光）；Chimalmat（不出聲）；假光造物的聲音（屬切片通用的「敵人」類，另批） | 避免同一個意思有兩種聲音 |

## G1：環境層

### S7-01　AMB-01 假光玻璃顫音層

```text
你是為 2D 惡魔城動作遊戲製作聲音的聲音設計師。
任務：製作環境音 AMB-01「地面森林」的「假光玻璃顫音層」：森林裡由珠寶反光凝成的假光造物附近，空氣中細碎、閃爍的玻璃聲。這一層疊在森林基底（風、葉、遠處蟲蛙）上，只在假光造物附近播放，靠近越大聲。世界規則是「虛假的東西是空的」。
限制：
- 聲音特徵：不規則、稀疏的高音薄玻璃輕觸，每一下極短（約 0.03 秒內起音、0.15 秒內收掉），有些後面帶一次更弱的短回聲；間隔 0.4～1.5 秒不等，偶爾出現 2～4 下快速相連的細碎小串（「顫音」），然後又回到稀疏
- 最重要的是：能量集中在 2 kHz 以上，幾乎沒有低頻；不可有持續的鳴響或嗡聲（那是「危險」類）；不可有音高逐漸上揚的段落（那是「前兆」類）；不可有規律、等距的節拍（那是「活物」類）；不可形成旋律或風鈴般的音階
- 長度：12 秒，首尾無縫循環、無爆音
- 響度：約 -30 LUFS；峰值不超過 -1 dBTP
輸出格式：WAV，48 kHz／16-bit，單聲道（遊戲內依造物位置定位），檔名 amb_01_forest_glass.wav；另附一句話說明實際做了什麼。
```

**驗收重點**：頻譜重心在 2 kHz 以上、200 Hz 以下幾乎沒有能量；沒有持續音；和森林基底 `amb_01_forest.wav` 疊在一起聽，玻璃聲聽得出來但不搶。

## G2：配樂

### S7-02　MUS-B01 Seven Macaw

```text
你是為 2D 惡魔城動作遊戲製作配樂的作曲家。
任務：製作 MUS-B01「Seven Macaw」：自稱太陽、渾身珠寶的鳥形對手的 Boss 戰配樂，三段戰鬥共用。他的光耀眼卻沒有根基：音樂要華麗、閃亮、帶戰鬥張力，但聽起來是空的。
限制：
- 音色只能用：陶笛（高音域，主旋律）、沙鈴（閃爍的節奏層）、木製縫鼓（只用中高音域的輕擊，維持節奏）；刻意缺少低頻：200 Hz 以下幾乎沒有能量
- 結構：中快板、穩定的節奏；陶笛旋律華麗、多裝飾音，但樂句常停在不穩定的音上、不給完整的終止感（空虛）；中段可以讓旋律稀疏一點、只剩沙鈴與縫鼓，再回來
- 為了讓玩家聽得清攻擊前兆，配樂不可有：持續、低平的低頻嗡聲（「危險」）；短促、上揚的吸氣或摩擦般的音效（「前兆」）；單發、乾短的空洞敲擊後帶一次回聲（「虛假」）；倒轉的氣音（「殘響」）。縫鼓要成串、有節奏，不可單發加回聲
- 不可使用：馬林巴、吉他、弦樂、西式合唱、泛用部落風鼓組；不可有任何語言的人聲或唱詞；不模仿特定儀式音樂、聖歌或任何既有的遊戲與電影配樂
- 長度：90 秒；首尾無縫循環、無爆音
- 響度：約 -18 LUFS；峰值不超過 -1 dBTP
輸出格式：WAV，48 kHz／16-bit，立體聲，檔名 mus_b01_sevenmacaw.wav；另附一句話說明實際做了什麼（含調性、速度、樂器的做法）。
```

**驗收重點**：200 Hz 以下能量明顯低於一般配樂；循環接縫聽不出來；和 `sfx_voc_tell_parry_*`、`sfx_voc_tell_heavy_*` 疊在一起時前兆仍清楚。

```text
- 響度：約 -18 LUFS；峰值不超過 -1 dBTP

```

**驗收重點**：聽得出 4～5 個上行音與最後的長音；不像前兆的噪聲蓄力。

### S7-10　假光閃耀（閃光瞬間）

```text
你是為 2D 惡魔城動作遊戲製作聲音的聲音設計師。
任務：製作 sfx_boss_sm_flash「假光閃耀」：聚集的光一次放出，面向他的人會被閃得眼前一片白。他自稱太陽，但這道光是假的、空的。
限制：
```
