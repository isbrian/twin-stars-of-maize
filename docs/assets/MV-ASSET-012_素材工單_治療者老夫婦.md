## 設計決定（Brian 2026-10-08）

| 項目 | 決定 | 理由 |
|---|---|---|
| 體態 | 兩人都瘦高、彎腰拄杖：四處行醫的旅行治療者 | 祖母矮小結實、在家；瘦高彎腰的剪影一眼分得開；「旅行」也交代了他們為什麼會經過 Seven Macaw 的地方 |
| 老爺爺頭髮 | 白色短髮＋稀疏的白鬍鬚 | 一眼看出是老爺爺；短髮不擋肩膀；和雙胞胎的馬尾、髮髻不同 |
| 老奶奶頭髮 | 白色長髮披在背後、不編不束 | 和祖母的辮子不同；不用髮髻，避開東亞造型；披在背後不擋近側手臂 |
| 化身暗示 | 完全不暗示，就是平凡老人 | ART_SPEC 第 2 節「不加神格化的圖像程式」；名稱表 D5 遊戲只稱「兩位老人」；西貒與長鼻浣熊的化身留給繪本文字 |
| 服裝與配色 | 褪色的麻灰與苔綠旅人衣物，白髮是唯一的亮色；爺爺素面腰布＋短披肩，奶奶素面上衣＋及踝裙 | 低彩度避開戰鬥訊號的高亮白（Seven Macaw 一戰滿是假光）；和祖母的暖色、Xbalanque 的藍綠分得開 |
| 鞋 | 簡單的皮涼鞋（AI 預設，Brian 可改） | 旅行的人；和赤腳的雙胞胎、祖母區分；ART_SPEC D-A1 允許簡單涼鞋 |
| 拐杖 | 基準圖空手；杖當成道具單獨生成一支，兩人共用造型，配握杖的手 | 和雙胞胎「空手基準圖＋武器另外生成＋握拳手」同一套做法；杖畫在基準圖上會擋住身體與腿 |
| 杖的造型 | 素面的天然樹枝木杖，頂端自然彎曲，沒有雕刻與裝飾 | 化骨組諸王（Bone Staff、Skull Staff）手持的是有名字的杖；平凡的樹枝才不會混淆，也不碰儀式權杖的意象 |
| 道具 | 奶奶斜揹一個素面的草藥網袋，深褐色、掛在背後高處 | 一眼看出是治療者；換牙時白玉米從袋子拿出來；照 Xbalanque 獵網的教訓：顏色和膚色明顯不同、不碰手臂 |
| 手部分件 | 兩人：張開的手（基準圖）＋握杖的手；奶奶另加托物的手 | 握杖對應走路；奶奶捧白玉米、爺爺動手換牙；托物的手照祖母的做法 |
| 姿勢 | 近側前臂與手伸在身體前方 | MV-ASSET-011 祖母第 1 輪「手臂垂下、要有空隙」三次都貼身，第 2 輪改成前臂伸在身前才通過 |

## 使用說明

1. 一則工單＝一則生成；依 CH-08 → CH-09 → CH-10 → CH-11 → CH-12 → WP-04 的順序，要附圖的照「附上」上傳。**Codex 的 image_gen 一次最多附 5 張參考圖。**
2. 原始輸出存到 `assets-test/chr_batch3/`（不進版控）。
3. 背景一律純洋紅 `#FF00FF`，方便去背；人物與物件身上不要用到洋紅。附上的定稿也是洋紅背景，prompt 已寫明那只是底色。
4. 中文 prompt 會讓模型往東亞造型偏，每則都寫了排除。
