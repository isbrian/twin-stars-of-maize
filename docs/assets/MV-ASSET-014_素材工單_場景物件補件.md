# MV-ASSET-014 素材工單：場景與物件補件

> **用途**：垂直切片子專案 b1 缺的場景與物件（[MV-SLICE-001b1 規格書](../../todo/spec/MV-SLICE-001b1_場景物件與HUD.md)「新工單 MV-ASSET-014」）
> **依據**：[ART_SPEC.md](../../ART_SPEC.md) 第 1～5、9、10 節；[CULTURAL_PRINCIPLES.md](../../CULTURAL_PRINCIPLES.md)；既有場景 [MV-ASSET-002](MV-ASSET-002_素材工單_第1批.md) A 部分、[MV-ASSET-003](MV-ASSET-003_素材工單_第2批.md) A 部分
> **建立日期**：2026-10-10
> **範圍**：寫 prompt → 交 Codex 生成 → AI 驗收（去背、縮放在 `tools/import_art.py` 做）

## 設計決定

Brian 2026-10-10 決定：缺的素材開新工單生成（SLICE-b6）、家前空地生成專屬中景（SLICE-b7）、門用小路標（SLICE-b9）。以下由 AI 依規格與原型決定：

| 項目 | 決定 | 理由 |
|---|---|---|
| Boss 入口閘門 | 藤蔓編的柵欄（直立的細木桿用藤蔓綁成），nance 樹與宮殿共用 | 兩處都是「身後的路被封住」；木桿與藤蔓在森林與宮殿都說得通，不必做兩件 |
| 宮殿的障壁 | 粗木條橫向綁成的木障 | 原型（MV-PROTO-002、003）的「木障」：只有希巴拉克的工具砍得碎；要和閘門的柵欄分得開 |
| 平台 | 一根完整的倒木（兩端自然斷口），依平台長度縮放，不做左右接續 | 切片的平台只有 320～420 px 三種長度，縮放不超過 1.3 倍；完整的一根比接續的長條自然 |
| 荊棘牆、閘門、障壁 | 上下可接續的直條，在遊戲裡縱向重複 | 碰撞從地面到頂（約 960～1100 px），一張圖畫不出那麼細長的比例 |
| 背景 | 家前空地與先前的中景一樣用透明背景；其餘物件用純洋紅 #FF00FF 背景，`import_art.py` 去背 | 物件的洋紅去背流程已驗證（MV-ASSET-010～013） |
| 網子 | 和 Xbalanque 肩上的獵網同材質（深褐粗繩、方形網目） | 原典 p.137：抓老鼠用的就是獵網 |

## 使用說明

1. 一則工單＝一件；附圖照「附上」（Codex 的 image_gen 一次最多 5 張）。附圖中的洋紅背景只是去背用的底色。
2. 輸出存到 `assets-test/b1_props/`（不進版控）；每件最多生成 3 次，選最好的一張存成下表檔名，其餘存成 `.v1.png`、`.v2.png`。
3. 不縮放、不裁切、不後製（去背與縮放由 `tools/import_art.py` 做）。
