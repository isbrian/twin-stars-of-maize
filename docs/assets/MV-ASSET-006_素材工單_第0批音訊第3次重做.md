### S0R3-06　殘響（第 3 次重做）

```text
你是為 2D 惡魔城動作遊戲製作聲音的聲音設計師。
任務：製作「殘響」類的聲音：玩家用聆聽能力看見死去的父親留下的殘影時聽到的聲音。世界規則是「死者留下殘響」：像死者在很遠的地方、倒著傳來的一聲嘆息。
限制：
- 聲音特徵：以氣音、呼氣般的噪聲為主體（像倒放的嘆息或倒放的風聲），從無聲慢慢漸強，到最強處突然停止；高頻柔和、聽起來遙遠朦朧；可以有很輕微、模糊的音色起伏
- 這一版最重要的是：不可有穩定、聽得出來的音高或持續的嗡聲（那是「危險」類的低鳴）；主體要是「氣」而不是「音」
- 也不可有清楚的敲擊起音或短促回聲（那是「虛假」類）；不可有規律脈動（那是「活物」類）；音色變化不可聽起來像音高往上爬的蓄力（那是「前兆」類）
- 不可使用：馬林巴、吉他、弦樂、西式合唱、泛用部落風鼓組；不可有任何語言的人聲或可辨認的人聲音節
- 長度：一個循環剛好 1.8 秒：前約 1.4 秒漸強後驟停，其餘是靜音，首尾無縫
- 響度：約 -20 LUFS；峰值不超過 -1 dBTP
- 做 3 個變體：氣音的質感與漸強曲線略有不同，但都是無音高、倒轉、驟停
輸出格式：WAV，48 kHz／16-bit，單聲道，檔名 sfx_voc_echo_01.wav 到 sfx_voc_echo_03.wav；另附一句話說明實際做了什麼。
```

## 驗收與重測

1. **格式與響度**（AI）：48 kHz／16-bit／單聲道、樣本數、約 -20 LUFS、峰值 ≤ -1 dBTP、首尾無縫。
