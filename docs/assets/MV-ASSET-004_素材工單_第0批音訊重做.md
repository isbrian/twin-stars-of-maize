## 使用說明

1. **一則工單＝一則 ChatGPT 訊息**，4 則在同一個新對話裡依序貼。整段複製 prompt 區塊即可，不用改字。
2. **存檔位置**：覆蓋 `assets-test/batch0/audio/` 的同名檔（不進版控）。第 1 輪的舊檔已備份在 `assets-test/batch0/audio_round1/`。
3. **製作紀錄**（條款規則 5）：prompt 就是本文件；保留 ChatGPT 的原始輸出檔與它附的一句說明。
4. **自己先聽時的注意**：不要用盲測台的 `--catalog` 模式聽，也不要把新舊檔對照著反覆聽，會讓重測偏樂觀。只確認「檔案能播、沒有爆音」即可。
5. **回報**：4 則都拿到後告訴我，我會驗收格式與響度，再同步進盲測台。

### S0R-02　真實（重做）

```text
你是為 2D 惡魔城動作遊戲製作聲音的聲音設計師。
任務：製作「真實」類的聲音：玩家用聆聽能力聽一個真實存在的物體（例如真正的石牆、真正的王座）時聽到的聲音。世界規則是「真實的東西會共振」：東西是實心的，敲下去整塊在振動。
限制：
- 聲音特徵：近距離、乾淨。一下有份量的起音（像手掌拍在厚重的石頭或實木上），接著是物體本身穩定、單一音高的振動，自然衰減，約 1 秒內完全收掉
- 這一版最重要的是：沒有任何空間回音或殘響效果、不可朦朧、不可像從遠處傳來（那是「殘響」類）；聽起來要像耳朵就貼在物體旁邊
- 也不可乾短空洞（那是「虛假」類）、不可有規律脈動（那是「活物」類）、不可有持續低鳴（那是「危險」類）
- 不可使用：馬林巴、吉他、弦樂、西式合唱、泛用部落風鼓組；不可有任何語言的人聲
- 長度：一個循環剛好 2.0 秒（起音在開頭，約 1 秒內收掉，其餘是靜音），首尾無縫
- 響度：約 -20 LUFS；峰值不超過 -1 dBTP
- 做 3 個變體：材質略有不同（例如石、厚木、陶），但都是近距離、乾淨、沒有回音
輸出格式：WAV，48 kHz／16-bit，單聲道，檔名 sfx_voc_real_01.wav 到 sfx_voc_real_03.wav，請直接提供可下載的檔案；另附一句話說明實際做了什麼。
```

**看什麼**：閉上眼聽，像是「就在旁邊敲了一下實心的東西」，而不是「遠處傳來的聲音」。聽得到房間回音就請它拿掉。

### S0R-04　虛假（假光）（重做）

```text
你是為 2D 惡魔城動作遊戲製作聲音的聲音設計師。
任務：製作「虛假」類的聲音（假光版）：玩家聽到由珠寶反光凝成的閃亮小生物時的聲音。它看起來華麗，其實是空的；世界規則是「虛假的東西是空的」。
限制：
- 聲音特徵：一下非常短（起音約 0.05 秒內）、高音、清脆的玻璃輕敲，約 0.2 秒後只帶一次較弱、同樣短的回聲，然後完全安靜。結構和「敲一下空心木頭、帶一次短回聲」完全一樣，只是材質換成薄玻璃
- 這一版最重要的是：完全沒有低頻、沒有持續的鳴響或嗡聲（那是「危險」類）、沒有低沉的共鳴（那是「前兆」類）、沒有長尾音（那是「真實」類）；兩下敲擊之間與之後都是靜音
- 不可使用：馬林巴、吉他、弦樂、西式合唱、泛用部落風鼓組、風鈴或鐘聲旋律；不可有任何語言的人聲
- 長度：一個循環剛好 1.6 秒（敲擊與回聲在開頭約 0.4 秒內結束，其餘是靜音），首尾無縫
- 響度：約 -20 LUFS；峰值不超過 -1 dBTP
- 做 3 個變體：玻璃的音高略有不同，但都是高音、極短、兩下就結束
輸出格式：WAV，48 kHz／16-bit，單聲道，檔名 sfx_voc_glass_01.wav 到 sfx_voc_glass_03.wav，請直接提供可下載的檔案；另附一句話說明實際做了什麼。
```

**看什麼**：只有「叮—叮」兩下就沒了；聽得到任何「嗡」或拖長的聲音，就請它拿掉。

### S0R-06　殘響（重做）

```text
你是為 2D 惡魔城動作遊戲製作聲音的聲音設計師。
任務：製作「殘響」類的聲音：玩家用聆聽能力看見死去的父親留下的殘影時聽到的聲音。世界規則是「死者留下殘響」：像從很遠的地方、或從過去傳來的回音，已經褪色。
限制：
- 聲音特徵：遠距離、朦朧。像倒放的回音：從無聲慢慢漸強，到最強處突然停止；整段帶很重的空間感（像在大洞穴的另一頭），高頻被濾掉、聽起來悶悶的；兩個非常接近的音高形成輕微搖曳
- 這一版最重要的是：音高全程保持不變或微微下沉，絕對不可上揚（上揚的蓄力聲是「前兆」類）；也不可近距離、乾淨、聽得到清楚的物體振動（那是「真實」類）；不可有清楚的敲擊起音
- 不可使用：馬林巴、吉他、弦樂、西式合唱、泛用部落風鼓組；不可有任何語言的人聲
- 長度：一個循環剛好 1.8 秒：前約 1.4 秒漸強後驟停，其餘是靜音，首尾無縫
- 響度：約 -20 LUFS；峰值不超過 -1 dBTP
- 做 3 個變體：音色與搖曳的速度略有不同，但都是遙遠、朦朧、音高不上揚
輸出格式：WAV，48 kHz／16-bit，單聲道，檔名 sfx_voc_echo_01.wav 到 sfx_voc_echo_03.wav，請直接提供可下載的檔案；另附一句話說明實際做了什麼。
```

**看什麼**：像隔著很遠的距離聽到的模糊聲音；聽起來像「越來越緊、越來越高」的蓄力就不對。

### S0R-08　前兆（不可招架）（重做）

```text
你是為 2D 惡魔城動作遊戲製作聲音的聲音設計師。
任務：製作「前兆」類的聲音（不可招架版）：敵人出重招前的蓄力聲，玩家一聽就知道「要出招了，而且擋不住，只能躲」。這個聲音不必聆聽就聽得到。
限制：
- 聲音特徵：由兩層同時發出、同時結束的聲音組成，總長約 0.4～0.6 秒：
  1. 上層：和一般出招前兆一樣，短促、音高明顯上揚的蓄力聲（例如快速吸氣、摩擦或拉緊的聲音）
  2. 下層：一層低沉、有壓迫感的「轟」聲，和上層同一瞬間開始、同一瞬間結束，音高也跟著微微上揚
- 這一版最重要的是：要讓人一聽就覺得「這是出招的蓄力，只是更重」；不可有回音或空間殘響（那是「殘響」類）、不可像敲擊空心物體（那是「虛假」類）；低音層不可在蓄力結束後延續成持續的嗡聲（那是「危險」類）
- 不可使用：馬林巴、吉他、弦樂、西式合唱、泛用部落風鼓組；不可有任何語言的人聲
- 長度：一個循環剛好 1.5 秒（蓄力聲在開頭，其餘是靜音），首尾無縫
- 響度：約 -20 LUFS；峰值不超過 -1 dBTP
- 做 3 個變體：蓄力與低音層的質感略有不同，但都是上揚、短促、同起同收
輸出格式：WAV，48 kHz／16-bit，單聲道，檔名 sfx_voc_tell_heavy_01.wav 到 sfx_voc_tell_heavy_03.wav，請直接提供可下載的檔案；另附一句話說明實際做了什麼。
```

**看什麼**：先想像一般的「咻—」蓄力，再加上底下一層「轟」；兩層一起停。聽起來像回音、或像敲到東西就不對。

2. **同步**：執行 `prototypes/p5-sound-test/sync_audio.sh`。
3. **重測**（Brian）：重測方式在重做的檔案到齊後再定。盲測台目前每輪出全部 24 題；只重測 4 種重做的聲音加上前兆（可招架），需要盲測台支援。
