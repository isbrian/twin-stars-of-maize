# MV-ASSET-013 素材工單：球具與老鼠的 HUD 圖示

> **用途**：垂直切片 HUD 的第 4 個武器圖示（球具）與第一個動物技能圖示（老鼠的鑽地突襲）；ART_SPEC 第 8 節「武器圖示 4 個、老鼠技能圖示」中缺的兩個
> **依據**：[ART_SPEC.md](../../ART_SPEC.md) 第 5、7、9 節；[MV-ASSET-002](MV-ASSET-002_素材工單_第1批.md) A1-15（既有的 HUD 元素與 5 個實物圖示，本批要和它們同一套）；[MV-ASSET-011](MV-ASSET-011_素材工單_角色基準圖第2批.md)（球具與老鼠的定稿）
> **建立日期**：2026-10-08
> **範圍**：寫 prompt → 交 Codex 生成 → AI 去背並縮成 128×128 → 目視驗收

## 設計決定（Brian 2026-10-08）

| 項目 | 決定 | 理由 |
|---|---|---|
| 球具圖示 | 護手（前臂護套）斜放 | 招架靠的是護手；長條斜放和吹箭、斧頭、掘棒的圖示同一種構圖，四個武器並排一致；護腰的 U 形縮到 48 px 不好讀 |
| 束帶顏色 | 紅褐、比定稿暗一階 | MV-ASSET-011 的設計本來就是「素面紅褐束帶」；HUD 上的鮮紅容易和受傷、血量聯想在一起 |
| 老鼠圖示 | 老鼠的頭與前半身從一小堆土裡鑽出來 | 一眼看出是老鼠，也看得出「從地下」的技能；只畫前半身讓頭夠大，縮小後眼睛耳朵還在 |
| 動物技能圖示的共通樣式 | 動物本身＋一個表示技能的小元素，不加底色或框 | 框由既有的技能槽外框提供；和武器、可可豆同屬「實物小圖示」（ART_SPEC 第 7 節）；之後兔子、蚊子、切葉蟻、隼照這個做 |
| 做法 | 各自生成一張 1024×1024 洋紅背景的大圖，AI 去背後縮成 128×128 透明 PNG | 和既有圖示的檔案規格一致（128×128、透明）；一則一件，附圖不超過 5 張 |

## 使用說明

1. 一則工單＝一則生成；附圖照「附上」上傳（Codex 的 image_gen 一次最多 5 張）。
2. 原始輸出存到 `assets-test/hud_batch2/`（不進版控）。
3. 背景純洋紅 `#FF00FF`；附上的既有圖示是透明背景、定稿是洋紅背景，prompt 已寫明洋紅只是底色。
4. 縮圖：AI 用 p4 的 `key_magenta` 去背，裁到內容、等比縮放置中到 128×128（四周留約 8 px），存成下表檔名。

| 工單 | 原始輸出 | 縮圖後 |
|---|---|---|
| UI-01 | `ui_icon_ballgear.source.png` | `ui_icon_ballgear.png` |
| UI-02 | `ui_icon_rat.source.png` | `ui_icon_rat.png` |

### UI-01　球具（護手）武器圖示

**產出**：`ui_icon_ballgear.png`
**附上**：`assets-test/chr_batch2/wpn_ballgear_armguard.png`（護手定稿）、`assets-test/batch1/art/ui_icon_axe.png`、`ui_icon_blowgun.png`、`ui_icon_digging_stick.png`（既有武器圖示，風格參考）

```text
你是為 2D 惡魔城動作遊戲繪製介面素材的美術設計師，風格是馬雅抄本與陶器彩繪的造型語言。
任務：製作武器「球具」的介面小圖示，放在畫面上的武器欄裡。附上的第一張是球具中「護手」的定稿：一個戴在前臂上的皮革護套，造型、材質照它；後面三張是同一欄裡已經定稿的斧頭、吹箭、掘棒圖示：構圖、輪廓線、配色方式、簡化程度必須和它們一致，四個圖示並排要像同一套。附圖中的洋紅色背景只是去背用的底色。
限制：
- 風格：平塗色塊、很粗的深色輪廓線、有限色盤；不畫任何投影或明暗漸層；簡化到只剩大形，細的磨痕與縫線都不畫
- 內容：只畫一個護手，從左下往右上斜放（和附上的武器圖示同一個角度）；素皮革褐色的護套、米白色的棉墊邊、兩道束帶；束帶畫成暗紅褐色（比定稿的紅更暗、更偏褐），不要鮮紅
- 在遊戲中顯示約 48～64 px，造型要簡潔、縮小後仍一眼看出是一個護套
- 不要：手或手臂；護腰、球或其他物件；任何文字、數字或符號紋樣；暗紫色、接近純白的高亮色；鮮紅色；洋紅色
- 構圖：圖示置中，佔畫面約 80%，四周留空
輸出格式：PNG，1024×1024 px，背景是純洋紅 #FF00FF（不透明），檔名 ui_icon_ballgear.source.png；另附一句話說明畫了什麼。
```

**看什麼**：和斧頭、吹箭、掘棒圖示並排像同一套（斜放、粗輪廓、簡化）；一眼看出是護套；束帶暗紅褐、不是鮮紅；縮到 48 px 仍可讀。

### UI-02　老鼠（鑽地突襲）技能圖示

**產出**：`ui_icon_rat.png`
**附上**：`assets-test/chr_batch2/chr_rat_reference.png`（老鼠定稿）、`assets-test/batch1/art/ui_icon_cacao.png`、`ui_icon_soup.png`（既有實物圖示，風格參考）、`assets-test/batch1/art/ui_skill_slot_frame.png`（技能槽外框，圖示會放在這個框裡）

```text
你是為 2D 惡魔城動作遊戲繪製介面素材的美術設計師，風格是馬雅抄本與陶器彩繪的造型語言。
任務：製作動物夥伴「老鼠」的技能小圖示。牠的技能是「鑽地突襲」：從地底下鑽出來咬敵人。附上的第一張是這隻老鼠的定稿，毛色、臉、耳朵照它；第二、三張是同一套介面裡已經定稿的可可豆與熱湯圖示：輪廓線、配色方式、簡化程度必須和它們一致；第四張是技能槽的外框，這個圖示之後會放在框的中間。附圖中的洋紅色背景只是去背用的底色。
限制：
- 風格：平塗色塊、很粗的深色輪廓線、有限色盤；不畫任何投影或明暗漸層；簡化到只剩大形，鬍鬚最多兩三根粗線，不畫一根根的毛
- 內容：老鼠的頭與前半身，從一小堆褐色的土裡往右上方鑽出來，兩隻前腳搭在土堆邊上；土堆是幾塊平塗的土塊與兩三顆小土粒，表示「從地下」；表情機靈、友善，不兇
- 在遊戲中顯示約 48～64 px，造型要簡潔、縮小後仍一眼看出是老鼠：大眼睛、圓耳朵、尖鼻子要清楚
- 不要：外框、圓形底色或任何背景；牙齒露出或咬東西的畫面；血、傷口；任何文字、數字或符號紋樣；暗紫色、接近純白的高亮色、紅色；洋紅色
- 構圖：圖示置中，佔畫面約 80%，四周留空
輸出格式：PNG，1024×1024 px，背景是純洋紅 #FF00FF（不透明），檔名 ui_icon_rat.source.png；另附一句話說明畫了什麼。
```

**看什麼**：和可可豆、熱湯圖示同一套畫風；一眼看出是老鼠、看得出從土裡鑽出；沒有框或底色；不兇、不露牙；縮到 48 px 眼睛耳朵仍在；放進技能槽外框大小合適。

## 驗收

| 項目 | 方法 | 通過條件 |
|---|---|---|
| 同一套 | 和既有 5 個圖示並排（128 px 與 48 px） | 輪廓線粗細、配色方式、簡化程度一致；四個武器圖示斜放角度一致 |
| 可讀性 | 縮到 48 px、灰階 | 一眼看出是護套、是老鼠 |
| 技能槽 | 老鼠圖示疊進 `ui_skill_slot_frame.png` | 不碰框、大小合適 |
| 顏色 | HSV 掃描＋目視 | 沒有暗紫、高亮白、洋紅；球具束帶不是鮮紅 |
| 文化與禁項 | 放大檢查 | 沒有文字、符號紋樣；老鼠不露牙、沒有血 |
| 技術 | 檢查檔案 | 128×128、透明背景、邊緣沒有洋紅毛邊 |
