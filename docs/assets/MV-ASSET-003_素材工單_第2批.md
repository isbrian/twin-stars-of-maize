## 使用說明

1. **一則工單＝一次交派**。prompt 區塊是交給 Codex 的完整指示。
2. **存檔位置**：`assets-test/batch2/art/`（不進版控）。原始生成圖存成 `*.source.png`，最終檔用工單指定的檔名。
3. **後製只限**：去背、縮放、裁切、以不抖動方式減色到 32 色以內。**不可用程式畫圖形、硬切透明區、或改動驗收表的判定**（第 1 批的教訓）。
4. **製作紀錄**（條款規則 5）：prompt 就是本文件；保留原始生成圖與 Codex 附的說明。

### 本批的設計決定

| 項目 | 決定 | 理由 |
|---|---|---|
| Boss 房的尺寸 | 兩個 Boss 房都是**單一畫面的競技場**，不需要左右無縫 | 省掉第 1 批最費工的接縫修正；左右兩側以樹叢或牆封住，鏡頭不捲動 |
| 畫面比例 | 生成 1536×1024，遊戲中放大 1.25 倍成 1920×1280，再裁成 1920×1080：**上下各約 80 px 會被裁掉**，重要內容不放在上下邊緣 | 工具輸出 3:2，遊戲畫面 16:9；放大不超過 2 倍（ART_SPEC 第 3 節） |
| 手臂 | 獨立成物件，不畫進背景；**由 Hunahpu 現成的分件在引擎中組成**，只生成繩圈（A2-04） | 雙胞胎之後要取回手臂，背景要能換成沒有手臂的狀態；生成工具拒絕生成被扯下的手臂（2026-10-05），改用分件也讓手臂與角色完全一致 |
| 手臂的斷口 | 肩端用繩圈層層纏住，看不到斷口 | 不見血（ART_SPEC 第 2 節） |
| 宮殿的火 | 畫在背景圖層裡，不沿用篝火素材 | 篝火是休息點的記號，出現在 Boss 房會讓玩家誤會 |
| 白玉米粒 | 象牙米白，不用純白 | 接近純白的高亮色保留給戰鬥訊號（ART_SPEC 第 5 節） |
| 特效 | 不交給生成工具 | 光源亮度、聚光、白茫、反光柱、光束、熄滅都在引擎裡用著色器與粒子做，素材只需要場景裡的金銀表面 |

```text

限制：
- 風格：平塗色塊、粗輪廓線、有限色盤、側面描繪；不畫任何投影、不畫明暗漸層
- 主角是畫面中央一棵高大、枝葉茂密的 nance 樹：樹冠寬，結滿光滑的黃色小果實（櫻桃大小，一串串掛在枝間）；樹頂有幾根粗壯、水平伸出的枝幹（大鳥會停在上面）
- 樹下兩側是茂密的低矮葉叢（雙胞胎躲藏的地方）；底部是一條平坦的林地地面
- 畫面左右兩側以濃密的樹叢與樹幹封住，看起來是被森林圍住的空地
- 畫布 1536×1024；遊戲中上下各約 80 px 會被裁掉，樹頂的枝幹與地面都不要貼在上下邊緣
- 色彩：森林的深綠、藍灰；nance 果實是溫暖的黃色，是畫面裡唯一鮮明的顏色；整體比角色低一階的飽和與明度

```

**看什麼**：一眼看得出中央的果樹與樹頂可停的枝幹；黃色果實是唯一的亮色；上下 80 px 內沒有重要內容；透明背景；沒有禁用色。
