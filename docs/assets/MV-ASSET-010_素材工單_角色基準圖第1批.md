# MV-ASSET-010 素材工單：角色基準圖第 1 批（Hunahpu 正式版、Xbalanque）

> **用途**：兩位主角的正式基準圖；遊戲骨架分件直接從基準圖切出，繪本插圖附上它們保持造型一致
> **依據**：[ART_SPEC.md](../../ART_SPEC.md) 第 1～4、9～12 節；[MV-PROTO-004 執行報告](../../report/MV-PROTO-004_美術管線_2026-10-02_2238_執行報告.md)「一致性結論」；[AI 素材條款與揭露](../legal/AI素材條款與揭露.md)
> **建立日期**：2026-10-08
> **範圍**：寫 prompt → 交 Codex 生成 → 驗收 → 切件並在 p4 原型試組（Brian 2026-10-08）

## 為什麼改做法

第 0 批的分件表是另外生成的，和基準圖的比例差距 201.8%（手臂細短、腰布過大），不能直接用。Brian 2026-10-08 決定改成：**基準圖直接畫成「分件友善姿勢」，分件從同一張圖切出**，比例由同一張圖保證。

| 項目 | 決定 |
|---|---|
| 姿勢 | 側面、面向右、空手；近側手臂微彎、離開身體，從肩膀到張開的手完整可見；兩腿一前一後分開、不重疊；遠側手臂藏在身後 |
| 遠側四肢 | 不從圖上切：用近側的分件複製、明度降一階（ART_SPEC 第 4 節原有規則） |
| 握拳的手 | 基準圖只有張開的手；握拳的手另外生成一張，切件時依張開的手的大小縮放對齊 |
| 武器 | 不畫在基準圖上；沿用第 0 批的斧頭、吹箭（`assets-test/batch0/art/`） |
| Hunahpu | 沿用第 0 批測試版的造型（臉、後腦馬尾、紅黃短披肩與腰布、泥彈袋），只改姿勢 |
| Xbalanque | ART_SPEC 第 4 節：冷色（藍綠、銀白）、較壯實、重心穩、肩上斜掛捲起的獵網；**頭頂短髮髻**（Hunahpu 是後腦馬尾），180 px 剪影就能分出兩人 |
| 180 px 可讀性 | Brian 判定第 0 批可讀，輪廓線與造型語言照舊 |

## 使用說明

1. 一則工單＝一則生成；依 CH-01 → CH-02 → CH-03 → CH-04 的順序，後面的工單要附前面的定稿。
2. 原始輸出存到 `assets-test/chr_batch1/`（不進版控）。
3. 背景一律純洋紅 `#FF00FF`，方便去背切件；人物身上不要用到洋紅。

### CH-01　Hunahpu 基準圖（正式版）

**產出**：`chr_hunahpu_reference.png`
**附上**：`assets-test/batch0/art/chr_hunahpu_reference.png`（第 0 批測試版，造型參考）

```text
你是為 2D 惡魔城動作遊戲繪製素材的美術設計師，風格是馬雅抄本與陶器彩繪的造型語言。
任務：重新繪製 Hunahpu 的角色基準圖正式版。附上的圖是他的測試版：臉、髮型、服裝、配件、配色都照它，完全一致；只有姿勢要改成下面指定的「分件友善姿勢」。這張圖之後會被直接切成頭、軀幹、手臂、腿等分件做骨架動畫，所以四肢不能遮住身體。
限制：
- 風格：平塗色塊、粗輪廓線（與附圖相同，約 16～18 px）、側面描繪、有限色盤；不畫任何投影、不畫明暗漸層；關節處（肩、肘、腕、膝、踝）不要畫暗色的圓形或切面陰影
- 造型（照附圖）：年輕男性、身形偏輕瘦、棕色膚色；黑色長髮在後腦束成馬尾；紅黃兩色的短披肩與腰布；腰間掛一個裝泥彈的小布袋
- 姿勢：全身側面、面向右側，站姿微微前傾；兩手都空著，不拿吹箭或任何東西
- 近側（靠近觀眾的）手臂：從肩膀自然垂下、手肘微彎、手臂離開身體約一個手掌的距離，手掌張開、手指併攏朝下；整條手臂從肩膀到指尖都完整可見，不和軀幹、腰布、袋子重疊
- 遠側手臂：藏在身體後面，看不到
- 雙腿：一前一後分開成小步，近側的腿在前、遠側的腿在後；兩條腿從腰布下方到腳趾都完整可見、彼此不重疊；赤腳
- 不要：頭冠、羽毛頭飾、白色頭帶、玉飾或大量首飾；身上的黑色斑點或美洲豹皮斑塊；任何文字或類文字符號；神祇圖像、曆法符號；阿茲特克或東亞（中國、日本、韓國）風格的髮型、服裝或紋樣；洋紅色
- 構圖：人物置中，頭頂到腳底約 1300 px，四周留空
輸出格式：PNG，直式 1024×1536 px，背景是純洋紅 #FF00FF（不透明），檔名 chr_hunahpu_reference.png；另附一句話說明畫了什麼。
```

**看什麼**：與測試版並排，臉、髮型、服裝、配色一致；近側手臂整條可見、不碰身體；兩腿不重疊；遠側手臂看不到；關節沒有暗色圓形；背景純洋紅。

### CH-03　Xbalanque 基準圖

**產出**：`chr_xbalanque_reference.png`
**附上**：CH-01 定稿

```text
你是為 2D 惡魔城動作遊戲繪製素材的美術設計師，風格是馬雅抄本與陶器彩繪的造型語言。
任務：製作 Xbalanque 的角色基準圖。他是英雄雙胞胎中沉穩、多謀的弟弟，和附圖中的哥哥 Hunahpu 是雙胞胎：畫風、輪廓線、身高、姿勢、構圖都必須和附圖一致，只有下面列出的地方不同。這張圖之後會被直接切成分件做骨架動畫，所以四肢不能遮住身體。
限制：
- 風格：與附圖完全相同；不畫任何投影、不畫明暗漸層；關節處不要畫暗色的圓形或切面陰影
- 和哥哥一樣的地方：年輕男性、棕色膚色、同樣的臉型與身高、腰布加短披肩、赤腳；姿勢與附圖相同（側面面向右、近側手臂垂下且手掌張開、遠側手臂藏在身後、兩腿一前一後不重疊、兩手空著）
- 近側手臂：和身體之間**要有看得到的洋紅色空隙**，從腋下一直到手都看得到空隙；手臂不碰軀幹、不碰腰布、不碰任何配件

  - 主色為冷色：藍綠與銀白，用在腰布與披肩上（哥哥是紅黃）
  - 配件：一個捲成一小捆的獵網，掛在**背後肩頸的高處**（披肩上方、後頸旁），只有一條細背帶從肩膀斜過胸口；獵網是**深褐色的繩網**（顏色要和膚色明顯不同）。獵網和背帶都不可以垂到腰部、不可以在手臂和身體之間、不可以碰到手臂；沒有泥彈袋
- 不要：頭冠、羽毛頭飾、白色頭帶、玉飾或大量首飾；美洲豹皮斑塊或黑色斑點；任何文字或類文字符號；神祇圖像、曆法符號；阿茲特克或東亞（中國、日本、韓國）風格的髮型、服裝或紋樣；洋紅色
- 構圖：人物置中，頭頂到腳底約 1300 px（與附圖相同），四周留空
輸出格式：PNG，直式 1024×1536 px，背景是純洋紅 #FF00FF（不透明），檔名 chr_xbalanque_reference.png；另附一句話說明畫了什麼。
```

**看什麼**：與 CH-01 並排像雙胞胎（臉型、身高、畫風一致）；冷色、較壯、頭頂髮髻；**近側手臂和身體之間有洋紅空隙**；獵網是深褐色、在背後高處、不碰手臂；灰階下兩人的剪影分得出來。

> **第 1 輪（2026-10-08）不通過**：三次生成的近側手臂都貼著身體，捲起的獵網卡在手臂與身體之間、被手臂擋住一部分；網子是米黃色，切件工具把它當成皮膚分給了上臂，軀幹上被擋住的網子也缺一塊。prompt 已加上「手臂與身體之間要有洋紅空隙」「獵網深褐色、掛在背後高處」，第 2 輪重做。

## 驗收

| 項目 | 方法 | 通過條件 |
|---|---|---|
| 文化 | 放大逐區檢查 | ART_SPEC 第 2 節；無偽文字、羽冠、斑點、東亞造型 |
| 造型一致 | CH-01 與測試版並排 | 臉、髮型、服裝、配色一致 |

| 雙胞胎 | 兩張基準圖並排、灰階 | 臉型身高一致；冷暖色、體型、髮型、配件一眼可分 |

| 技術 | 檢查檔案 | 洋紅背景可乾淨去背；尺寸與命名照本工單 |
