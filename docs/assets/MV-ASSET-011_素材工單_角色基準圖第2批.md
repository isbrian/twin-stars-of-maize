> **範圍**：寫 prompt → 交 Codex 生成 → 目視驗收（Brian 2026-10-08）。姿勢照「分件友善」規則畫，但**切件與骨架試組留到切片要用時**：p4 的切件工具與骨架是為雙胞胎寫的，祖母（長裙）與老鼠（四足）要另寫骨架

## 設計決定（Brian 2026-10-08）

| 項目 | 決定 | 理由 |
|---|---|---|
| 祖母體態 | 年長、矮小結實、背微彎但站得穩；比雙胞胎矮約一個頭 | 家常、勤勞、溫暖（CULTURAL_PRINCIPLES 原則 1）；剪影和雙胞胎、之後的治療者老夫婦都容易分 |
| 祖母髮型 | 灰白長髮編成一條辮子垂在背後，辮尾綁素面布條 | 避開東亞髮髻；不擋近側手臂；和 Hunahpu 馬尾、Xbalanque 髮髻不同；不用當代 K'iche' 的盤頭頭飾（特定社群的文化符號） |
| 祖母服裝 | 素面直筒短袖上衣＋及踝裹裙＋布腰帶，只用簡單橫條 | 古典期與當代都有的基本形制；織紋會被畫成偽文字，當代 huipil 的紋樣也代表特定村落；短袖讓手臂完整可見，及踝裙讓下半身成一件 |
| 祖母配色 | 米白上衣、陶土紅褐裙、玉米黃腰帶 | 家、爐火、玉米的溫暖；明度與彩度比 Hunahpu 的紅黃低，分得開；不碰暗紫與高亮白 |
| 祖母的手 | 基準圖是張開的手；另外生成「掌心朝上、托物的手」 | 照雙胞胎「握拳手另外生成、依張開手縮放」；遞物時把既有的熱湯碗 `prop_soup_bowl` 疊在掌心 |
| 老鼠造型 | 寫實比例的森林鼠，褐灰毛，表情機靈友善 | 原典是一般的老鼠；「機靈」對應牠用情報換食物 |
| 老鼠尾巴 | 普通細長無毛的鼠尾，不畫燒傷 | 已登記的改編：以溫和的交換加入（原典是先被抓、燒了尾巴）；不畫傷口 |
| 老鼠尺寸 | 遊戲裡身長約角色身高的 1/3（約 60 px） | 鑽地突襲是戰鬥技能，要看得清；所以輪廓要粗、細節要少 |
| 護腰 | 素面 U 形厚護腰：木框外包皮革、內襯棉墊，用繩綁在腰上 | 原典的 yokes；不用考古常見、刻有蟾蜍或神像的石製儀式 yoke（ART_SPEC 第 2 節） |
| 護手 | 前臂皮革護套＋棉墊，蓋前臂與手背、不包手指；兩隻前臂都戴 | 招架用前臂擋；不包手指，張開手與握拳手分件照用；遠側照既有規則複製近側、調暗 |
| 球具配色 | 素皮革褐＋米白棉＋素面紅褐束帶，稍有使用痕跡 | 中性色，兩兄弟都配得上；「舊」暗示父輩用過、藏了很多年；序章的「過去」由引擎調色 |
| 球具做法 | 當成武器單獨生成護腰、護手、球；切件時依軀幹寬、前臂長自動縮放 | 和握拳手同一種做法；同一套要給雙胞胎與父輩共用，獨立成件才能套到不同人身上 |
| 橡膠球 | 實心、素面、深褐近黑的天然橡膠球，約人頭大小的 2/3（AI 預設，Brian 可改） | 原典藏起的用具是「護腰、護臂與球」；繪本 BB-09、BB-18 要用 |

## 使用說明

1. 一則工單＝一則生成；依 CH-05 → CH-06 → CH-07 → WP-01 → WP-02 → WP-03 的順序，要附圖的照「附上」上傳。
2. 原始輸出存到 `assets-test/chr_batch2/`（不進版控）。
3. 背景一律純洋紅 `#FF00FF`，方便去背；人物與物件身上不要用到洋紅。附上的雙胞胎基準圖也是洋紅背景，prompt 已寫明那只是底色。
4. 中文 prompt 會讓模型往東亞造型偏（繪本 A 組的教訓），每則都寫了排除。
