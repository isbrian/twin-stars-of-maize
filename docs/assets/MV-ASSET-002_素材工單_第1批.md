做法和第 0 批相同：

1. **一則工單＝一則 ChatGPT 訊息**。整段複製「prompt」區塊貼上即可，不用改字。
2. **對話分組**：場景（A1-01～09）一個對話、物件與圖示（A1-10～15）一個對話、環境音（S1-01～03）一個對話；同組依編號順序做，讓 ChatGPT 保有前面的定稿當上下文。
3. **要附圖的工單**會寫「附上：」，請把指定的檔案一起上傳。
4. **存檔位置**：原始輸出存到 `assets-test/batch1/art/`、`assets-test/batch1/audio/`（不進版控）。
5. **製作紀錄**（條款規則 5）：prompt 就是本文件；保留 ChatGPT 的原始輸出檔與它附的說明，不要覆蓋。
