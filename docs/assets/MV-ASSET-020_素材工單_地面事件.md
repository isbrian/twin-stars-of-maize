# MV-ASSET-020 素材工單：地面事件（動物、食物、尾巴）

> **用途**：[MV-SLICE-001c3b](../../todo/spec/MV-SLICE-001c3b_地面事件素材與動作.md) 把 c3a 地面過場的佔位剪影換成正式素材：入夜時讓田地復原的動物（鹿、兔子、長鼻浣熊）、兄弟倆抓下的鹿尾與兔尾、給老鼠的玉米與豆子（可可沿用 `prop_cacao_bean.png`）。
> **依據**：[ART_SPEC.md](../../ART_SPEC.md) 第 1～3 節（畫風、色盤、文化限制）；[MV-DESIGN-002 原典核對](../design/MV-DESIGN-002_原典核對.md) 第 5 項（老鼠的食物見原典 p.138；鹿和兔子的尾巴被抓斷見 p.135～137）；[CULTURAL_PRINCIPLES.md](../../CULTURAL_PRINCIPLES.md)
> **建立日期**：2026-10-19
> **範圍**：寫 prompt → Codex 生成（Brian 2026-10-19 定案 SLICE-c3b-1、2）→ AI 驗收 → `import_art.py` 匯入

## 設計決定

| 項目 | 決定 | 理由 |
|---|---|---|
| 動物 | 彩色側面、面向左、奔跑或跳躍中；單張圖（遊戲裡上下彈跳、調成夜色） | 過場裡從右往左跑過田地；和角色畫風一致、看得出種類（SLICE-c3b-1） |
| 物種 | 白尾鹿、棉尾兔、長鼻浣熊 | 中美洲原生；鹿和兔子是原典裡被抓斷尾巴的動物 |
| 尾巴 | 單獨一截乾淨的毛，不畫血或傷口 | 年齡層；過場的笑點（尾巴從此很短） |
| 食物 | 中美洲原生玉米（可夾紅紫粒）、三色菜豆 | 原典 p.138 的食物 |

## 使用說明

1. 輸出存到 `assets-test/c3b_art/`（不進版控）；每張最多生成 3 次，選最好的一張存成下表檔名，其餘存成 `.v1.png`、`.v2.png`。
2. 不縮放、不裁切、不後製；背景純洋紅 #FF00FF（不透明）。
3. 附圖：`assets-test/chr_batch1/chr_hunahpu_reference.png`（雙胞胎：畫風、線條粗細）、`assets-test/chr_batch2/chr_rat_reference.png`（老鼠：動物的畫法）。附圖的洋紅色背景只是去背用的底色。
