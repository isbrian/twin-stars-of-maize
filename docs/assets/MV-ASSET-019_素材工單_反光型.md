## 設計決定

| 項目 | 決定 | 理由 |
|---|---|---|
| 行為（c4c1 定案） | 站著不走；舉起反光面蓄力 1.0 秒 → 射出貼地水平光束；反光面擋正面；繞到背後打 | 見規格書 SLICE-c4c-1～14 |
| 造型 | 和爬行型、飛行型同一類：寶石片與金銀薄片拼成、片間有空隙看得到裡面是空的；矮壯、兩隻粗短的腳站著，比爬行型大一號；前方一隻粗短的金屬臂托著一面**反光面** | 「中型、站著」和低矮多腳的爬行型、懸空的飛行型剪影分得開 |
| 反光面 | 橢圓形的打磨金銀面，**略轉向觀者**（看得到橢圓形的面，不是側邊細板）；中央一顆小寶石（蓄力時的「光點」位置）；用平塗的明暗色帶表現反光，不畫漸層、光暈、放射紋 | 玩家要一眼看出「那是一面會反光的東西、朝著哪邊」；不能像太陽圓盤（ART_SPEC 文化限制） |
| 分件預留 | 反光面（含托著它的臂）和身體之間留明顯空隙，不重疊 | c4c2 要把反光面切成獨立一件，才能舉起、放下、轉向 |
| 遊戲尺寸 | 約 160×140 px（含反光面） | c4c1 判定框 |

### R-01　假光造物・反光型 基準圖

**附上**：`assets-test/batch2/chr/enm_falselight_crawler_reference.png`（爬行型：畫風、輪廓線粗細、寶石與金屬薄片的質感照它）、`assets-test/batch2/chr/enm_falselight_flyer_reference.png`（飛行型：同一類，剪影要分得開）、`assets-test/chr_b2b1/parts/chr_sevenmacaw_reference.png`（Seven Macaw：配色參考）

```text
你是為 2D 惡魔城動作遊戲繪製素材的美術設計師，風格是馬雅抄本與陶器彩繪的造型語言。
任務：製作敵人「假光造物・反光型」的基準圖：和附上的爬行型、飛行型同一類，由自稱太陽的 Seven Macaw 身上的珠寶反光凝成；它站在原地，舉起手中的一面反光面，把光集中成一道光束射向玩家，反光面也像盾牌一樣擋住正面的攻擊；看起來閃亮，其實是空的。附上的第一張是爬行型：畫風、輪廓線粗細、寶石與金屬薄片的質感照它；第二張是飛行型（同一類，剪影要和它們分得開）；第三張是 Seven Macaw，配色參考。附圖的洋紅色背景只是去背用的底色。這個造物在遊戲中約 160×140 px，所以輪廓要粗、細節要少。這張圖之後會被切成身體、腳、反光面等分件做骨架動畫。
限制：
- 風格：平塗色塊、粗輪廓線（約 28 px，同爬行型）、側面描繪、有限色盤；不畫任何投影、不畫明暗漸層、不畫光暈或放射光
- 造型：矮壯的身體由一片片紅、金、藍、綠的寶石片與金屬薄片拼成，片與片之間有空隙，從空隙看得到裡面是空的（透出洋紅色背景）；兩隻粗短的腳穩穩站著；沒有眼睛、嘴巴，頂端一塊較大的寶石當作「頭」；不要做成任何真實存在的動物或人
- 反光面：身體前方（左側）一隻粗短的金屬臂，托著一面橢圓形的打磨金銀反光面，高度約和身體一樣；反光面略轉向觀者，看得到橢圓形的面；面上用兩三道平塗的淺色帶表現反光，中央鑲一顆小寶石；反光面和臂要與身體之間留明顯的空隙、互不重疊
- 姿勢：側面、面向左側，反光面放在胸前高度（中立姿勢）；腳、身體、反光面都看得到
- 不要：太陽圓盤、放射狀光芒、扇形或任何太陽圖樣；徽章或盾徽的圖案；真實動物的特徵（觸角、眼睛、口器、毛）；血、傷口；任何文字、類文字符號、曆法符號；東亞風格紋樣；紅色當作危險色的光、暗紫色、接近純白的高亮色；洋紅色（空隙除外）
- 構圖：造物連反光面置中，整體寬約 1000 px，四周留空
輸出格式：PNG，橫幅 1536×1024 px，背景是純洋紅 #FF00FF（不透明），檔名 enm_falselight_reflector_reference.png；另附一句話說明畫了什麼。
```

**看什麼**：
- 和爬行型、飛行型同一類（寶石片、金銀薄片、片間空隙），剪影分得開；矮壯、站著。
- 反光面看得出是一面朝左、會反光的橢圓面，不像太陽圓盤或盾徽；和身體之間有空隙、可以切成獨立一件。
- 縮到約 160 px 寬、在深綠森林底上看得出身體與反光面的朝向。
