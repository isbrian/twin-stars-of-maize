> **用途**：給 MV-PROTO-004（美術管線）與 MV-PROTO-005（聲音語彙盲測）的測試素材
> **依據**：[ART_SPEC.md](../../ART_SPEC.md)、[AUDIO_SPEC.md](../../AUDIO_SPEC.md)、[AI 素材條款與揭露](../legal/AI素材條款與揭露.md)
> **建立日期**：2026-10-01

## 使用說明

1. **一則工單＝一則 ChatGPT 訊息**。整段複製「prompt」區塊貼上即可，不用改字。
2. **美術與音訊各開一個對話**：美術工單 A0-01～A0-05 在同一個對話裡依序完成，讓 ChatGPT 保有前面的定稿當上下文；音訊工單另開對話。
3. **要附圖的工單**會寫「附上：」，請把指定的檔案一起上傳。
4. **存檔位置**：原始輸出存到 `assets-test/batch0/art/` 或 `assets-test/batch0/audio/`（不進版控）。這批是測試素材，原型驗證通過後才轉為正式素材。
5. **製作紀錄**（條款規則 5）：prompt 就是本文件；請保留 ChatGPT 的原始輸出檔與它附的一句說明，不要覆蓋。
6. **驗收**：每則工單附有「看什麼」，不符合就請 ChatGPT 依該點修改，或回報給我調整 prompt。
7. **回報**：做完一則或卡住時，告訴我工單編號與結果即可。

## 音訊工單

給 MV-PROTO-005 盲測台使用。盲測台會讓每個聲源**循環播放**，所以這批每個檔案都是「一個循環」：聲音在開頭，其餘補靜音，首尾無縫。各類響度要相近，避免受測者靠音量大小分辨。

### 共通說明（每則都已寫進 prompt，這裡只供對照）

| 項目 | 規格 |
|---|---|
| 格式 | WAV，48 kHz／16-bit，單聲道 |
| 變體 | 每類 3 個，聽起來是同一類、細節略有不同 |
| 響度 | 各類相近，約 -20 LUFS；峰值不超過 -1 dBTP |
| 循環 | 首尾無縫、無爆音 |

### 八類與循環長度

| 工單 | 類別 | 檔名 | 一個循環 |
|---|---|---|---|
| S0-01 | 活物 | `sfx_voc_alive_01～03.wav` | 1.0 秒 |
| S0-02 | 真實 | `sfx_voc_real_01～03.wav` | 2.0 秒 |
| S0-03 | 虛假（木） | `sfx_voc_hollow_01～03.wav` | 1.6 秒 |
| S0-04 | 虛假（假光） | `sfx_voc_glass_01～03.wav` | 1.6 秒 |

### S0-01　活物

```text
你是為 2D 惡魔城動作遊戲製作聲音的聲音設計師。
任務：製作「活物」類的聲音：玩家用聆聽能力聽一個活的生物時聽到的聲音。世界規則是「活的東西有心跳和呼吸」，要讓人一聽就知道「這是活的」。
限制：
- 聲音特徵：低頻、規律的心跳「咚—咚」，加上很輕的呼吸氣息；不可有持續不斷的嗡聲（那是「危險」類）、不可有乾短的敲擊回聲（那是「虛假」類）
- 不可使用：馬林巴、吉他、弦樂、西式合唱、泛用部落風鼓組；不可有任何語言的人聲
- 長度：一個循環剛好 1.0 秒，首尾無縫
- 響度：約 -20 LUFS；峰值不超過 -1 dBTP
- 做 3 個變體：同樣是心跳加呼吸，節奏與音色細節略有不同
輸出格式：WAV，48 kHz／16-bit，單聲道，檔名 sfx_voc_alive_01.wav 到 sfx_voc_alive_03.wav，請直接提供可下載的檔案；另附一句話說明實際做了什麼。
```

### S0-02　真實

```text
你是為 2D 惡魔城動作遊戲製作聲音的聲音設計師。
任務：製作「真實」類的聲音：玩家用聆聽能力聽一個真實存在的物體（例如真正的石牆、真正的王座）時聽到的聲音。世界規則是「真實的東西會共振」。
限制：
- 聲音特徵：一次飽滿、紮實的共鳴，帶有自然、慢慢消失的長尾音；不可乾短（那是「虛假」類）、不可有規律脈動（那是「活物」類）
- 不可使用：馬林巴、吉他、弦樂、西式合唱、泛用部落風鼓組；不可有任何語言的人聲
- 長度：一個循環剛好 2.0 秒（共鳴在開頭，尾音自然消失），首尾無縫
- 響度：約 -20 LUFS；峰值不超過 -1 dBTP
- 做 3 個變體：材質感略有不同（例如石、厚木、陶），但都要飽滿有尾音
輸出格式：WAV，48 kHz／16-bit，單聲道，檔名 sfx_voc_real_01.wav 到 sfx_voc_real_03.wav，請直接提供可下載的檔案；另附一句話說明實際做了什麼。
```
