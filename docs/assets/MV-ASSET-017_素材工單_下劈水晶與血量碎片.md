## 設計決定

| 項目 | 決定 | 理由 |
|---|---|---|
| 下劈水晶的造型 | Seven Macaw 的「假光結晶」：一顆懸空、多面切割的寶石，紅、金、藍、綠珠寶色，平塗、粗輪廓；不發光、不畫光暈 | 和假光造物同一套珠寶色，一看就知道是「假光的東西」；假光無影、不畫真光（ART_SPEC 第 1 節） |
| 水晶的可讀性 | 外輪廓是清楚的菱形或六角形，比背景亮一階、邊緣粗黑線 | 玩家要在森林的深綠底上一眼看到「這可以打」 |
| 血量碎片 | 血條圓片（`ui_health_pip_full.png`：金邊、綠色分段外框、青綠圓片）的**左半片** | 撿到的東西和血條上的半格一模一樣，不用解釋就懂；ART_SPEC 第 7 節要求抽象幾何 |
| 撿取物與 HUD 半格 | 同一張半片圖的兩個尺寸：撿取物約 64 px（地上要看得到）、HUD 半格 40×40（與現有血條圖示同尺寸、同畫布） | 一張設計、兩種用途 |
| 森林木障 | 綠藤綁著的一排粗木樁，可上下無縫接續；和宮殿木障同一種用法（寬 60 px、縱向重複），但材質是森林的：沒有金色箍環，用綠藤纏綁 | 宮殿木障的金箍是宮殿的材質；擋路、可以砍的東西在森林裡要看起來屬於森林。要和荊棘牆（會扣血的地形）、關門戰的藤蔓柵欄分得開 |

## 使用說明

1. 一則工單＝一件。C-04 附上的圖見該節。C-02、C-03 都附上 `game/art/ui/ui_health_pip_full.png`，以它為準畫左半片。
2. 輸出存到 `assets-test/c4a_art/`（不進版控）；每件最多生成 3 次，選最好的一張存成下表檔名，其餘存成 `.v1.png`、`.v2.png`。
3. 不縮放、不裁切、不後製（去背由 `tools/import_art.py` 做）。

| # | 檔名 | 生成尺寸 | 背景 | 用途 |
|---|---|---|---|---|
| C-01 | `prop_pogo_crystal.png` | 1024×1024（遊戲內約 96 px） | 洋紅 | 下劈水晶 |
| C-02 | `prop_health_fragment.png` | 1024×1024（遊戲內約 64 px） | 洋紅 | 地上的血量碎片 |
| C-03 | `ui_health_pip_half.png` | 1024×1024（遊戲內 40×40） | 洋紅 | 血條末端的半格 |
| C-04 | `prop_forest_barrier.png` | 1024×1536（遊戲內寬 60，縱向重複到約 900～1300） | 洋紅 | 森林木障（MV-SLICE-001c4b） |

共通限制（每則 prompt 都已寫入）：平塗色塊、粗輪廓線、有限色盤、不畫投影與明暗漸層、不畫光暈或放射光；不要太陽圓盤、放射狀光芒或任何太陽圖樣；不要任何文字、類文字符號、曆法符號、可辨識的宗教或曆法圖形；不要東亞風格紋樣；物件上不要出現洋紅色。

### C-01　下劈水晶（假光結晶）

```text
你是為 2D 惡魔城動作遊戲繪製素材的美術設計師，風格是馬雅抄本與陶器彩繪的造型語言。
任務：畫一顆懸浮在空中的「假光結晶」。玩家在空中往下攻擊打中它會被彈起，所以它要在深綠色的森林背景前一眼就看得出來「可以打」。它是 Boss「Seven Macaw」用假光造出來的東西，假光看起來耀眼，但其實不發光、沒有影子。附圖的洋紅色背景只是去背用的底色。
限制：
- 一顆多面切割的寶石，外輪廓是清楚的菱形或細長六角形，上下兩端尖，正面看得到 4～6 個切面
- 配色：紅、金、藍、綠四種珠寶色分布在不同切面；切面之間用粗黑輪廓線分開；整體比深綠森林亮一階
- 寶石中央可以有一小塊金色薄片當作「假的光點」，但不要畫光暈、放射光或發光的邊
- 置中、四周留白，物件約佔畫布的 70%
- 風格：平塗色塊、粗輪廓線、有限色盤；不畫投影、明暗漸層、光暈或放射光
- 不要：太陽圓盤、放射狀光芒或任何太陽圖樣；任何文字、類文字符號、曆法符號；東亞風格紋樣；物件上的洋紅色
輸出格式：PNG，1024×1024 px，背景是純洋紅 #FF00FF（不透明），檔名 prop_pogo_crystal.png；另附一句話說明畫了什麼。
```

**看什麼**：
- 縮到 96 px 時仍看得出輪廓與四種顏色；在深綠背景前清楚。

### C-04　森林木障（綠藤綁著的木樁，縱向接續）

**附上**：`game/art/prop/prop_palace_barrier.png`（宮殿的木障：同一種用法，森林版要換材質）、`game/art/prop/prop_platform_log.png`（森林的原木平台：木頭的畫法要一致）、`game/art/prop/prop_thorns_wall.png`（荊棘牆：要分得開）、`game/art/prop/prop_arena_gate.png`（藤蔓柵欄：要分得開）

```text
你是為 2D 惡魔城動作遊戲繪製素材的美術設計師，風格是馬雅抄本與陶器彩繪的造型語言。
任務：製作森林裡擋路的「木障」：一排粗木樁直立並排、用綠色藤蔓纏綁在一起，玩家拿到新能力後可以砍碎它。它在遊戲裡是一條很細長的直條（寬約 60 px、高約 900～1300 px），所以這張圖要能上下無縫接續、在遊戲裡縱向重複。附上的第一張是宮殿裡的木障（同樣的用法，但金色箍環是宮殿的材質，森林版不要）；第二張是森林的原木平台，木頭的顏色、木紋與輪廓線粗細要和它一致；第三張是荊棘牆、第四張是藤蔓柵欄，木障要和這兩張一眼分得開。附圖中的洋紅色只是去背用的底色。
限制：
- 風格：平塗色塊、很粗的深色輪廓線、有限色盤；不畫投影與明暗漸層
- 內容：三根粗木樁直立、緊緊並排，彼此之間沒有任何空隙；整排佔畫面寬約 60%、從畫面最上緣到最下緣；木樁是褐色、有直的木紋（和森林原木平台同色系）；每隔約畫面高的 1/4 有一道綠色藤蔓斜斜纏繞、同時綁住三根木樁，藤蔓上有幾片小葉子
- 上下兩端要能接續：最上一列與最下一列像素要能接上（木樁在上下兩端都是被畫面切斷的，不畫木頭的端面與尖頭）
- 和荊棘牆分得開：沒有尖刺、沒有荊棘；和藤蔓柵欄分得開：是粗木樁密合成牆，不是細木桿加藤蔓
- 兩側是洋紅背景
- 不要：金色箍環或金屬；梯子的造型、橫向木條、門、把手、雕刻、人物；太陽圖樣、放射狀或扇形造型、紋章；文字、數字、符號紋樣；紅色、暗紫色、接近純白的高亮色；物件上的洋紅色
輸出格式：PNG，1024×1536 px，背景是純洋紅 #FF00FF（不透明），檔名 prop_forest_barrier.png；另附一句話說明畫了什麼。
```

**看什麼**：
- 縮到 60 px 寬時讀起來是「綁起來的木牆」，在深綠森林前看得清楚；上下可接續。
- 和宮殿木障（金箍）、荊棘牆（尖刺）、藤蔓柵欄（細桿）都一眼分得開。
- 整合：`tools/import_art.py` 照宮殿木障加一列（`fit_width: 60`、`key: hard`）；`world/room.gd` 的 `BARRIER_TEX` 換成 `res://art/prop/prop_forest_barrier.png`。
