## 背景與目的

依 [原型驗證計畫](../../docs/design/MV-PROTO-000_原型驗證計畫.md) 第 3 節，回答三個問題：

1. 「換人＝換武器」的即時連段順不順？
2. 球具招架看不看得懂、抓不抓得到？
3. 兄弟的專屬能力讓探索「需要換人」但不煩？

上層依據：[VISION.md](../../VISION.md) 6.1、6.2、6.4；[討論紀錄](../../docs/design/MV-DESIGN-001_討論紀錄.md) 議題 B（B1、B3、B4）、E（E1、E2、E2-1、E6 按鍵方案 A）；[ART_SPEC.md](../../ART_SPEC.md) 第 5 節（戰鬥訊號）；[AUDIO_SPEC.md](../../AUDIO_SPEC.md) 第 2 節（聲音語彙）。

**不做**：Boss、動物技能、聆聽、美術、音樂、正式的換武器介面（選單或休息點，留給垂直切片）。

**原型的簡化**：正式遊戲中二段跳與「讓工具自己動」要打倒 Seven Macaw 才取得（VISION 6.4）；原型為了測試，一開始就給。

### 定案（Brian，2026-10-05）

| 編號 | 問題 | 定案 | 理由 |
|---|---|---|---|
| PROTO2-1 | 什麼時候可以換人 | **幾乎隨時；攻擊中只在收招**：自由狀態（地面、空中）、攻擊或招架的收招、翻滾結束後都能換；出招與判定中、翻滾中、治療中、受擊硬直中不能換 | 與 PROTO1-3「只有收招能被取消」同一套規則；讓「打完 → 換人 → 接著打」成立，又保留亂按會被打的代價 |
| PROTO2-2 | 換人的代價 | **短冷卻、沒有無敵、沒有入場攻擊** | 冷卻防連按來回跳；無敵只屬於翻滾（PROTO1-2 的分工）；先測純換人夠不夠順 |
| PROTO2-3 | 血量 | **兩人共用一條血、共用治療次數** | 場上一人，換人純粹為了武器與能力；與成長設計（只有一份上限）一致 |
| PROTO2-4 | 掘棒與斧頭的區分 | **掘棒＝長距離突刺**：射程約斧頭的 1.5 倍、判定窄、出招稍慢；傷害相同 | 原典是掘土的木鋤（Christenson 註 348）；「保持距離 vs 貼身」成為選擇理由，又不會變成「更強」 |
| PROTO2-5 | 招架成功的效果 | **敵人長硬直，球具本身不傷人** | 「招架 → 換人 → 輸出」就是要測的連段 |
| PROTO2-6 | 招架的判定 | **按下後短窗口，沒按準有破綻** | 白揮的代價讓「練習後成功率上升」有意義 |
| PROTO2-7 | 球具的空中下劈 | **也能下劈彈跳，但不傷人** | 下劈是兩人共通（E2-1）；平台段誰都過得去 |
| PROTO2-8 | 武器分配 | **預設 Hunahpu 斧頭、Xbalanque 球具；除錯鍵 1／2／3 改目前場上的人的武器** | 一開始就能測招架連段；正式換武器方式留給垂直切片 |
| PROTO2-9 | 「讓工具自己動」的發動 | **Xbalanque 的吹箭射中木障時發動** | 方案 A 沒有空鍵；沿用吹箭的瞄準與「觸發機關」職責（B3）；「射了沒反應 → 換人」本身就是不靠提示的引導 |
| PROTO2-10 | 二段跳的恢復 | **落地或下劈彈起才恢復，空中換人不刷新** | 與彈跳段的節奏一致；避免「換人刷跳」破壞關卡高度設計 |
| PROTO2-11 | 探索區 | **三個關卡、交替換人**，最後一間小戰鬥房 | 包含「同一個障礙要兩人接力」 |
| PROTO2-12 | 招架成功率怎麼量 | **程式自動記錄、依分鐘分段**，另加一個招架練習對象 | 驗收 ② 有數字佐證 |
| PROTO2-13 | 實作方式 | **同一個角色身體，換人時切換「角色資料」**；武器改成資料 | 既有狀態機、輸入緩衝、受擊、彈跳全部沿用；空中換人與收招換人不必處理兩個物理物件的交接 |

### 具體變更

#### 1. 兩兄弟

| | Hunahpu | Xbalanque |
|---|---|---|
| 灰盒主色 | 暖色（沿用 `Color(0.85, 0.55, 0.25)`） | 冷色（藍綠，例 `Color(0.25, 0.65, 0.7)`） |
| 預設武器 | 斧頭 | 球具 |
| 專屬能力 | 二段跳 | 讓工具自己動 |

- 兩人的跑速、跳躍、翻滾、吹箭等基礎數值**完全相同**，差別只在武器與能力，讓測出的差異確定來自「換人＝換武器」。
- 灰盒尺寸沿用 60×180。

#### 2. 換人

| 項目 | 規則 |
|---|---|
| 按鍵 | 手把 Y、鍵盤 Tab |
| 可以換 | 自由狀態（地面或空中）、攻擊或招架的**收招**、翻滾剛結束 |
| 不能換 | 攻擊或招架的出招與判定中、翻滾中、治療中、受擊硬直中 |
| 輸入緩衝 | 沿用 `action_buffer`（0.1 秒）：不能換時按下，會在第一個能換的幀執行 |
| 冷卻 | `swap_cooldown` 0.3 秒；冷卻中按下直接忽略（冷卻比緩衝長，不排隊） |
| 保留 | 位置、速度、面向、血量、治療次數、無敵計時、二段跳是否已用 |
| 重置 | 換上場的人一律回到自由狀態；上一位的收招不延續、攻擊判定立即關閉 |
| 無敵 | 換人本身不給無敵 |
| 回饋 | 角色以新的主色閃一下、佔位音效「換人」、HUD 更新 |

#### 3. 武器

三種武器都有側攻、上攻、下劈（下劈只在空中）三個方向；動作時間分出招 → 判定 → 收招，收招可被翻滾、跳躍、換人取消（PROTO1-3、PROTO2-1）。

| | 斧頭 | 掘棒 | 球具 |
|---|---|---|---|
| 側攻 | 弧形揮砍，判定 140×120 | 往前突刺，判定 210×60 | 招架 |
| 上攻 | 判定 120×150 | 往上突刺，判定 60×210 | 招架 |
| 下劈 | 判定 120×150，會彈跳 | 往下突刺，判定 60×210，會彈跳 | 用護腰往下撞，判定 120×150，會彈跳 |
| 出招／判定／收招 | 0.06／0.08／0.18 秒（沿用） | 0.10／0.08／0.22 秒 | 招架見第 4 節；下劈同斧頭 |
| 傷害 | 4 | 4 | 0（下劈也是 0） |

- 判定框一律貼著角色的面向側（側攻）、頭頂（上攻）、腳下（下劈）。
- 斧頭的現有數值與行為不變（MV-PROTO-001 的測試不用改）。
- 傷害為 0 的命中**仍會觸發下劈彈跳**，但不觸發命中停頓、敵人閃白、扣血。

#### 4. 球具招架

| 項目 | 規則 |
|---|---|
| 動作 | 按攻擊（側或上）→ 招架窗口 `parry_window` 0.2 秒 → 收招 `parry_recovery` 0.35 秒 |
| 方向 | 只擋**正面**（角色面向那一側）來的攻擊；背後被打照常受傷 |
| 成功 | 窗口內被**可招架**（白色圓形）的攻擊打到 → 這次攻擊無效、敵人硬直 `parry_stagger` 1.2 秒、白色圓形光環擴散（ART_SPEC 第 5 節）、佔位音效「招架」、角色**當幀結束收招**（可立即換人或翻滾） |
| 不可招架 | 窗口內被**不可招架**（暗紫鋸齒）的攻擊打到 → 照常受傷 |
| 窗口外 | 收招中被打 → 照常受傷 |
| 硬直 | 招架造成的硬直與吹箭打斷的硬直是同一種狀態，只是時間較長；招架**不受**吹箭打斷冷卻限制 |

「可招架」與「不可招架」沿用敵人身上既有的攻擊屬性：爬行型的撲擊可招架、飛行型的俯衝不可招架。

#### 5. 二段跳（只有 Hunahpu）

| 項目 | 規則 |
|---|---|
| 高度 | 第二跳高度＝`jump_height` × `double_jump_ratio`（0.75，即 300 px）；放開跳躍鍵一樣會削減 |
| 時機 | 離地後可用一次；從平台走下去時，若仍在土狼時間內，第一下算一般跳躍 |
| 恢復 | 落地，或下劈命中彈起 |
| 換人 | 「本次滯空的二段跳已用」記在身體上；空中換人來回不刷新。Xbalanque 在空中按跳躍沒有反應 |
| 回饋 | 佔位音效「二段跳」；角色腳下一圈小光點（灰盒） |

#### 6. 讓工具自己動（只有 Xbalanque）與木障

| 項目 | 規則 |
|---|---|
| 發動 | Xbalanque 射出的飛鏢射中木障 |
| 工具 | 從 Xbalanque 身上生成（灰盒：一把小斧頭形狀的方塊），以 `tool_speed` 900 px/s 飛向木障，到達後砍 `tool_chops` 3 下、共 `tool_chop_time` 0.6 秒，木障碎掉，工具飛回 Xbalanque 的位置後消失 |
| 數量 | 同時只有一把工具在外；工具在外時再射中木障沒有反應 |
| 換人 | 工具在外時換人，工具照樣完成工作並飛回場上的人身上 |
| 對象 | 只對木障有效，不會打敵人、不會被敵人打 |
| 其他攻擊 | Hunahpu 的飛鏢、任何人的近戰打在木障上：一聲悶響、沒有效果。悶響是低沉、短、**沒有回聲**的撞擊，避開「虛假」語彙（乾短的空洞敲擊＋一次回聲） |
| 木障外觀 | 灰盒木色長方形，加幾道斜紋，和地形一眼可分；實心，擋路、擋飛鏢 |
| 重置 | 碎了就一直碎著；F10 重置房間時復原 |

#### 7. 測試房間的延伸

依 MV-PROTO-001 初始數值計算：單跳高 400 px、二段跳總高約 700 px、單跳水平約 650 px、角色高 180 px。

```text
[ 戰鬥房 ] [ 平台段 ] → ① 高台 → ② 懸空木障 → ③ 台階＋木障 → [ 小戰鬥房 ]（盡頭牆）
```

| 關卡 | 配置 | 通過方式 |
|---|---|---|
| ① 高台 | 一階高 550 px 的台階（單跳搆不到、二段跳有約 150 px 餘裕） | Hunahpu 二段跳 |
| ② 懸空木障 | 寬 600 px 的坑；正中央一道木障，從這段的天花板垂到地面高度；木障離兩側坑緣各約 300 px（大於掘棒判定 210 px，近戰打不到）；天花板讓角色無法跳過木障 | Xbalanque 在坑緣用吹箭標記；破障後誰都能跳過（坑寬在單跳範圍內） |
| ③ 台階＋木障 | 一階高 550 px 的台階，頂端往內 100 px 處一道木障直頂天花板 | 需要兩人：Xbalanque 從底下斜射破障再換 Hunahpu 跳上，或 Hunahpu 先上去再換 Xbalanque 近距離射 |
| 小戰鬥房 | 1 隻爬行型、1 隻飛行型；盡頭是牆 | 探索途中遇敵時換人 |

- ②③ 兩段有天花板，高於地面約 950 px：二段跳時頭頂最高約 880 px，不會撞到；② 的木障從天花板一路垂到地面高度。
- 原本的右牆移到小戰鬥房盡頭。
- 掉進新的坑：沿用平台段規則，扣 1 血、回到該坑的左側坑緣。
- 探索區**不放任何文字提示**（驗收 ③）。
- 具體座標在實作計畫中依上表計算；改了跳躍數值後要重算（見「與 MV-PROTO-001 自評的關係」）。

**招架練習對象**：放在戰鬥房入口（起點右側），一進場就會經過。

| 項目 | 規則 |
|---|---|
| 行為 | 原地不動；每 `dummy_interval` 2.0 秒出一次可招架的撲擊，前搖訊號、前搖時間、判定與爬行型完全相同，但不往前移動 |
| 血量 | 不會死（受到傷害不扣血，只閃白） |
| 招架 | 成功時同樣硬直 1.2 秒，之後重新計時 |

#### 8. HUD、操作與佔位音效

**HUD**（灰盒，可以用文字）：左上角沿用血量、治療次數；下面兩行顯示兩兄弟：場上的人亮色「Hunahpu　斧頭」，另一位淡色「Xbalanque　球具」；換人或改武器時立即更新。

**操作**（方案 A，新增部分；其餘沿用 MV-PROTO-001）：

| 動作 | 手把 | 鍵盤 |
|---|---|---|
| 換人 | Y | Tab |
| 除錯：改目前場上的人的武器 | — | 1 斧頭／2 掘棒／3 球具（兩人可拿同一種） |
| 除錯：存回數值 | — | F9：存回數值、印出數值表，**並印出招架紀錄** |
| 除錯：重置房間 | — | F10：同 MV-PROTO-001，另外復原木障、讓兩人回到預設武器；**招架紀錄不清除** |

**佔位音效**（沿用程式合成）：換人、招架成功、二段跳、工具飛出、工具砍擊、木障碎裂、打在木障上的悶響。只為手感回饋，不代表正式音色；全部避開 AUDIO_SPEC 第 2 節各類語彙的特徵。

**招架紀錄**：每按一次招架記一筆（時間、結果）。結果有三種：成功、白揮（窗口內沒有被任何攻擊打到）、窗口內被不可招架的攻擊打到。F9 印出時以「從遊戲啟動算起的第 N 分鐘」分段，每段列出嘗試次數、成功次數、成功率。紀錄只在關閉遊戲時清除。

#### 9. 自動驗證（`--self-test`）

沿用 MV-PROTO-001 的格式（`SELFTEST PASS|FAIL <項目>`、`SELFTEST SUMMARY`、失敗時非 0 結束碼、另 grep `SCRIPT ERROR`）。

| 類別 | 驗證內容 |
|---|---|
| 換人 | 自由狀態（地面、空中）換人後角色資料、主色、武器跟著換，位置、速度、面向、血量不變 |
| | 攻擊出招與判定中按換人不會換；收招中會換；出招中按下 → 收招第一幀換（輸入緩衝） |
| | 翻滾、治療、受擊硬直中不能換；翻滾結束後能換 |
| | 冷卻內再按不會換 |
| | 共用血量：Hunahpu 受的傷換成 Xbalanque 後仍在 |
| 武器 | 敵人放在「斧頭判定框外、掘棒判定框內」的距離：掘棒側攻打得到，斧頭打不到 |
| | 掘棒、球具的下劈都能彈跳；球具下劈不扣血 |
| | 球具側攻、上攻不扣血 |
| 招架 | 窗口內被爬行型撲擊打到：不受傷、敵人硬直 1.2 秒、紀錄＋1 成功 |
| | 窗口內被飛行型俯衝打到：受傷、紀錄＋1「被不可招架打到」 |
| | 收招中被打：受傷；該次紀錄為白揮 |
| | 背後被打：受傷 |
| | 招架成功的同一幀就能換人 |
