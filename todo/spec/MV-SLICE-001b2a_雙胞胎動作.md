## 背景與目的

b1 把雙胞胎畫成靜態立繪（SLICE-b10）。b2a 把它們換成**骨架與動作**，讓作品集的展示影片與試玩版裡，玩家操控的角色真的會跑、會跳、會揮武器。玩法、碰撞與數值完全不變。

**不做**：覺醒、開場、倒下等演出動作（c，SLICE-b3）；敵人、Seven Macaw（含 SLICE-b12 的判定框與光源）、祖母、老鼠、老夫婦、Chimalmat（b2b）；判定框與數值（SLICE-b4）；「通關時間不足 30 分鐘」的內容量問題（總規格「待處理」，留給 c／d 的規格書）。

## 架構

```
assets-test/chr_batch1/parts/ ──import_art.py──▶ game/art/chr/parts/{角色}/*.png
prototypes/p4-art-pipeline/rig/{角色}_rig.json ──tools/（換算到遊戲尺寸）──▶ game/rig/{角色}_rig.json
                                                         game/rig/twin_anims.json（AI 編寫）
                                                         game/rig/attachments.json（AI 編寫）
Player（狀態、速度、攻擊段落、場上的人、斷臂、瞄準）
   └─▶ world/twin_animator.gd：決定（動作, 時間）＋吹射覆寫
           └─▶ world/rig_view.gd：依資料組出 Skeleton2D／Bone2D／分件 Sprite2D；pose(動作, 時間)
```

### 資料

| 檔案 | 內容 | 誰寫 |
|---|---|---|
| `game/rig/{角色}_rig.json` | 關節座標、每個分件掛哪根骨頭與偏移 | 工具從 p4 的 rig json 依同一比例換算產生，不手寫 |
| `game/rig/twin_anims.json` | 每個動作：影格（各骨頭角度＋骨盆位移）、是否循環；攻擊類另標每格屬於出招／判定／收招 | AI 編寫 |
| `game/rig/attachments.json` | 武器、球具、湯碗掛在哪根骨頭、偏移與角度 | AI 編寫 |

### 執行時

- `world/rig_view.gd`：角色進場時依資料組出骨架；`pose(動作, 時間)` 以 12 fps 取最近的影格（不內插）。**不用 AnimationPlayer**：姿勢必須是玩家目前狀態的純函式，攻擊三段的長度才能直接讀數值表（F9 改數值後自動同步），也最好測。
- `world/twin_animator.gd`：每幀依玩家狀態決定動作與時間；吹射在主動作之後覆寫頭與雙臂的角度。
- 兩兄弟各組一副骨架，只顯示場上那位；面向用整副骨架水平翻轉。
- 顏色規則（受擊閃白、無敵與翻滾半透明、治療綠色）從 `world/portrait.gd` 抽成共用函式，立繪與骨架都用。
- 骨架畫在玩家節點後面（`show_behind_parent`），程式畫的訊號照舊在上面；玩家的灰盒身體不畫（同 b1 的 `portrait_drawn`）。
- 雙胞胎的立繪換成骨架；敵人與 NPC 的立繪不動（b2b）。

### 開發工具（只在開發版生效）

| 參數 | 作用 |
|---|---|
| `--rig-view` | 動作展示畫面：兩兄弟依序播每個動作；按鍵切換彩色／灰階、暫停、逐格 |
| 錄影 | `godot --path game -- --rig-view --frames <資料夾>`：逐格輸出 1920×1080 的 JPG（彩色與灰階各一輪），錄完自動結束，再用 ffmpeg 合成（實作時改：Movie Writer 只錄得到視窗大小，視窗被專案設定與螢幕夾在 1920×1080 以下；見執行報告） |

## 自測（`--self-test` 新增）

| 項目 | 內容 |
|---|---|
| 組裝 | 兩兄弟每個分件都在；站姿身高約 180 px（±5%）；腳底對齊碰撞框底部；組好的站姿與基準圖疊合差距 ≤ 2 px |
| 關節不露縫 | 每個動作的每一格，關節處都有分件蓋住（沿用 p4 的 `test_joints_covered_in_every_key`） |
| 狀態對應 | 每個玩家狀態（含空中上升／下落、落地、各武器 × 方向、招架、受擊、治療、翻滾）對到正確的動作 |
| 攻擊同步 | 出招／判定／收招各段的時間點，姿勢落在該段的影格；把 `axe_startup` 改大，姿勢時間跟著拉長 |
| 吹射 | 射出後 0.3 秒內手臂朝瞄準角度（±10°），之後回到主動作；邊跑邊射時腿照跑 |
| 武器與球具 | 武器圖跟著裝備換；球具只在裝備時顯示護腰、護手；斷臂時近側手臂與武器隱藏，覺醒後回來 |
| 換人 | 只有場上那位的骨架可見；入場姿勢可被移動與攻擊打斷 |
| 視覺規則 | 受擊閃白、無敵與翻滾半透明、治療綠色作用在骨架上；招架小盾與光環畫在骨架上面 |
| 玩法不變 | 子專案 a 與 b1 的 258 項照舊通過（含從新遊戲自動走到結尾） |

截圖與效能：`--shots` 照拍；換成骨架後每個畫面平均幀時間仍 ≤ 16.7 ms。
