## 背景與目的

依 [原型驗證計畫](../../docs/design/MV-PROTO-000_原型驗證計畫.md) 第 3 節，回答三個問題：

1. 以《Hollow Knight》為主、借《死亡細胞》的手感能不能成立？
2. 翻滾無敵與跳躍閃避的分工清不清楚？
3. 吹箭（低傷害、打斷）會不會架空近戰？

上層依據：[VISION.md](../../VISION.md) 6.2；[討論紀錄](../../docs/design/MV-DESIGN-001_討論紀錄.md) 議題 B（B1、B3、B4、B7、B8）、E6（按鍵方案 A）；[ART_SPEC.md](../../ART_SPEC.md) 第 3、5 節（尺寸、戰鬥訊號）。

**不做**：換人、技能、Boss、招架（球具在 MV-PROTO-002）、美術、音樂。

### 定案（Brian，2026-10-02）

| 編號 | 問題 | 定案 | 理由 |
|---|---|---|---|
| PROTO1-1 | 調數值的方式 | **參數檔＋編輯器邊玩邊改**：數值集中在一個 `.tres`，從編輯器啟動後用遠端檢查器即時改；按 F9 存回參數檔並印出數值表 | Godot 原生功能，不用自製介面；數值只有一個來源；002、003 沿用 |
| PROTO1-2 | 翻滾在空中能不能用 | **只能在地面** | 翻滾＝水平閃避（有無敵）、跳躍＝垂直閃避（無無敵），分工最清楚；空中位移留給之後覺醒的二段跳、空中衝刺 |
| PROTO1-3 | 攻擊能不能被取消 | **只有收招能被翻滾或跳躍取消** | 保留「亂按會被打」；借死亡細胞的快節奏，打完能馬上閃 |
| PROTO1-4 | 碰到敵人身體會不會受傷 | **不會，只有攻擊判定會傷人** | 每次受傷都有前搖可讀；翻滾穿過敵人的判斷更寬容 |
| PROTO1-5 | 吹箭打斷的規則 | **前搖中射中就打斷，同一隻有冷卻** | 吹箭的價值在抓時機；冷卻防止遠距離鎖死敵人，秒數可調，原型直接量出問題 3 的答案 |
| PROTO1-6 | 治療中被打 | **中斷、不回血，次數照扣** | 1 秒硬直才是真的代價；讀招延伸到治療時機 |

### 具體變更

#### 1. 畫面與比例

- 畫面基準 1920×1080（ART_SPEC 第 3 節），視窗縮放時等比例縮放。
- 角色灰盒 60×180 px（角色在畫面上約 180 px 高），數值換成正式素材後可直接沿用。
- 鏡頭跟隨角色、平滑移動、限制在房間邊界內。

#### 2. 操作（方案 A）

| 動作 | 手把 | 鍵盤＋滑鼠 |
|---|---|---|
| 移動 | 左搖桿 | A／D |
| 上攻／下劈 | 左搖桿上＋攻擊／空中左搖桿下＋攻擊 | W＋攻擊／空中 S＋攻擊 |
| 跳躍（按住跳得更高） | A | Space |
| 翻滾（只能在地面） | B | Shift |
| 攻擊 | X | 滑鼠左鍵 |
| 吹箭 | 右搖桿瞄準＋RT；右搖桿沒推時朝面向射 | 滑鼠右鍵，朝游標射 |
| 治療 | 十字鍵上 | R |
| 除錯：存回數值 | — | F9：把目前數值存回 `combat_tuning.tres`，並在主控台印出 Markdown 數值表 |
| 除錯：重置房間 | — | F10：角色回起點、血量與治療補滿、敵人全部重生 |

吹箭的瞄準來源依「最後使用的裝置」判斷：最後一個輸入是滑鼠就朝游標，是手把就用右搖桿或面向。

#### 3. 角色狀態機

| 狀態 | 進入條件 | 規則 |
|---|---|---|
| 自由（待機、跑、上升、落下） | 預設 | 可移動、跳躍、攻擊、射吹箭；地面上可翻滾、治療 |
| 攻擊 | 按攻擊 | 出招 → 判定 → 收招；**攻擊中仍可左右移動**（HK）；出招與判定中不能被取消；**收招可被翻滾或跳躍取消**（PROTO1-3）；攻擊中不能射吹箭 |
| 翻滾 | 地面上按翻滾（PROTO1-2） | 往輸入方向（沒輸入則面向）移動固定距離；無敵只在中段區間；結束後有冷卻；不能攻擊、射吹箭 |
| 治療 | 地面上按治療且有次數 | 按下立刻扣次數；硬直約 1 秒、不能移動；硬直結束才回血；硬直中受擊 → 中斷、不回血（PROTO1-6） |
| 受擊 | 被攻擊判定打中且不在無敵中 | 扣血、擊退、短暫失去控制；之後保持無敵一段時間（半透明閃爍）；血量歸零 → 重置房間 |

手感輔助（業界常規，不另外定案）：土狼時間（離開平台後短時間內仍可起跳）、跳躍緩衝（落地前按跳會被記住）、可變跳躍高度（放開跳躍鍵時削減上升速度）、落下時重力加大、落下速度上限。

#### 4. 攻擊與吹箭

| 項目 | 規則 |
|---|---|
| 斧頭三方向 | 側攻（面前）、上攻（頭上）、下劈（只在空中，腳下） |
| 下劈彈跳 | 下劈打中敵人或彈跳物 → 角色得到固定的向上速度（B8），可再次下劈 |
| 命中反饋 | 命中停頓（hitstop）、敵人閃白、輕微晃鏡頭、側攻打中時角色輕微後退 |
| 吹箭 | 低傷害、無限、有射速限制（B3）；自由瞄準，可邊跑邊射、空中也能射 |
| 吹箭打斷 | 敵人**前搖中**被飛鏢射中，且該敵人的打斷冷卻已結束 → 攻擊取消、進入硬直，開始打斷冷卻；冷卻中敵人身上有暗色標記，射中只扣血（PROTO1-5） |
| 近戰不打斷 | 斧頭打中前搖中的敵人只扣血、不打斷，打斷是吹箭專屬（B3「專門打斷前搖」） |
| 敵人吸附 | 這一版不做；B3-1 的吸附只對弱點與機關 |

#### 5. 敵人（假光造物）

共用規則：

- 碰觸身體不傷人，只有攻擊判定會傷人（PROTO1-4）；角色可以穿過敵人。
- 前搖訊號（ART_SPEC 第 5 節）：輪廓亮起，並在敵人上方顯示訊號——可招架＝白色**圓形**、不可招架＝暗紫**鋸齒**。這一版沒有招架，訊號用來測「讀不讀得出來」。
- 死亡：碎成光點（灰盒用小方塊粒子）。

| | 爬行型 | 飛行型 |
|---|---|---|
| 血量 | 12（斧頭 3 下） | 8（斧頭 2 下） |
| 平常 | 在地面左右巡邏 | 在玩家斜上方盤旋 |
| 發現 | 玩家進入水平 450 px 內 | 玩家進入 700 px 內 |
| 前搖 | 0.6 秒，白色圓形（可招架） | 0.7 秒，暗紫鋸齒（不可招架） |
| 攻擊 | 往前撲：1100 px/s、0.35 秒 | 朝「前搖開始時玩家的位置」俯衝：1400 px/s，碰到地面或飛滿 900 px 停止 |
| 收招 | 0.8 秒原地，近戰空檔 | 在地面停 0.8 秒，近戰空檔；之後飛回盤旋高度 |
| 傷害 | 1 | 1 |

#### 6. 測試房間

```text
[ 戰鬥房 約 2400 px 寬 ]              [ 平台段 ]
 起點  爬行 ×2  飛行 ×1  兩個高台      坑邊 ─ 坑（約 1100 px 寬）─ 對岸
                                         上方 3 個彈跳物
```

- 戰鬥房：平地＋兩個可跳上的高台；2 隻爬行型、1 隻飛行型。
- 平台段：坑寬約 1100 px，超過一般跳躍的水平距離（初始數值下約 650 px：滯空約 0.73 秒 × 跑速 900 px/s），必須連續下劈彈跳 3 次才過得去（驗收 3）。彈跳物放在坑邊算起約 250、550、850 px 處。
- 彈跳物：懸空的假光結晶，站不上去、碰到不傷人，只能被下劈打中。
- 掉進坑：扣 1 點血，回到坑邊重來。
- 血量歸零：整個房間重置（同 F10）。

#### 8. 佔位音效

沿用 P1 的程式合成做法（不需外部檔案）：揮擊、命中、吹箭發射、打斷、受擊、治療完成、彈跳、碎裂。只為了手感回饋，不代表正式音色。

#### 9. 自動驗證（`--self-test`）

執行：`godot --headless --path prototypes/core -- --self-test`。每項結果印一行 `SELFTEST PASS|FAIL <項目>`，最後印 `SELFTEST SUMMARY pass=N fail=M`，有失敗時以非 0 結束碼離開。

| 項目 | 驗證內容 |
|---|---|
| 傷害 | 斧頭命中扣 4、飛鏢命中扣 1 |
| 受擊無敵 | 受擊後無敵時間內的第二次攻擊不扣血；時間過後會扣 |
| 翻滾無敵 | 無敵區間內受擊不扣血；區間外會扣 |
| 治療 | 回血不超過上限；次數用完後無法治療；硬直中受擊 → 不回血、次數照扣 |
| 下劈彈跳 | 角色在彈跳物上方下劈命中後，垂直速度為向上的彈跳速度 |
| 吹箭打斷 | 前搖中命中 → 進入硬直；冷卻中再次在前搖中命中 → 只扣血、不硬直 |
| 近戰不打斷 | 前搖中被斧頭打中 → 扣血、仍維持前搖 |
| 攻擊取消 | 出招與判定中按翻滾無效；收招中按翻滾立刻進入翻滾 |
| 空中翻滾 | 空中按翻滾無效 |

#### 10. 除錯與調數值流程

1. 從 Godot 編輯器開啟 `prototypes/core`，按 F5 執行。
2. 編輯器的「遠端」場景樹選 Player → 檢查器裡的 `tuning` 參數檔可直接改，改完立即生效（程式每幀讀取參數，不快取）。
3. 調到滿意按遊戲內 F9：存回 `combat_tuning.tres`，主控台印出 Markdown 數值表，直接貼進原型驗證計畫（驗收 5）。
