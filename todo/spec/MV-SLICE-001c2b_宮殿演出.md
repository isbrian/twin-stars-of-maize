## 背景與目的

c2a 做好了過場機制與 nance 樹的三段。c2b 把宮殿的三張文字卡（`toothache`、`teeth`、`death`）換成引擎內演出，並修正 c2a 延後、c2b 會直接踩到的機制問題。死亡用 c1 的熄滅效果（`MacawGlints.extinguish`）與宮殿假光。

## 範圍

### 機制修正（`world/cutscene/`）

- `cs.together(callables: Array)`：同時開始幾個指令，全部做完才 return（取代「不 await 的背景指令」）。跳過時立刻 return。
- `run()` 已在執行時再呼叫：`push_error` 並 return，不重跑。
- HUD 透明度只在演出期間（`running`）寫。
- 交還操作的順序：最後一段播完（或跳過）後，同一幀依序**移除替身 → 換回戰鬥鏡頭 → 恢復真角色的顯示 → 解凍戰場 → 依序呼叫各段的 `end_state`**，再收黑邊。`end_state` 對顯示的設定（例如藏起 Boss）不會被蓋掉。
- `cs.hide(node)`：演出期間藏起任何真正的節點（例如老夫婦），交還時恢復。
- 替身 `actor.gd`：骨架節點名稱改為 `Rig`、加 `faced_body()`（Seven Macaw 用 `MacawAnimator.BODY` 依面向翻），讓 `MacawGlints.attach(actor)` 可以直接用；`add_glints()` 掛上身上光點。

### 三段演出

旁白與台詞皆為現有文字卡原句。舞台位置：`STAGE_X := 15100`（他伏低的位置，面向左；伏低時頭約在 `STAGE_X − 220`）。雙胞胎替身站在真正角色的位置（不移動）；老夫婦替身從 `COUPLE_X`（−45、+25）出發。

**第 2 段開場**（第一次進宮殿；約 8 秒）

1. 他在寶座前（x 約 15250）面向寶座，捧著下顎哀嚎（`wail`）；奇瑪瑪特在寶座旁。
2. 旁白：「七金剛鸚鵡坐在寶座邊上，牙痛得不停哭喊。」
3. 旁白：「奇瑪瑪特在寶座旁。」
4. 他轉向入口、展翅（`spread`），展翅時退回起始位置，收翅（倒播 `spread`）後站定（最終審查修正，Brian 2026-10-15 決定）。旁白：「他看見老人身後的兩個孩子，猛然站了起來。」
5. 黑邊收起，開打。
- 結束狀態：`palace_card_seen = true`；之後 `_start_fight()` 照舊。

**換牙**（第 2 段設局成功；約 10 秒）

1. 他跳到舞台（`fly` 約 0.6 秒）、面向左、伏低（`bow`）。七金剛鸚鵡：「可憐可憐我，治好我的牙吧。」
2. 兩位老人走到他頭前（`walk`），伸手（`reach`），背影擋住他的嘴。旁白：「老人取出他的牙，換上一粒粒發亮的白玉米。」換頭成白玉米牙（頭 2）。
3. 老人退回入口端；他起身（`idle_ground`）。旁白：「他的臉立刻垮了下來，看起來不再像王。」
4. 黑邊收起，第 3 段開打。
- 結束狀態：`phase = 3`；之後 `_start_fight()` 照舊（`lights_removed = 2` 已在設局時設好）。

**死亡**（第 3 段設局成功；約 20 秒）

1. 他跳到舞台、伏低；兩位老人走到他頭前伸手。旁白：「老人又摘去他眼中的貴金屬。」換頭成失明（頭 3）。
2. 老人退開兩步；他起身、呆望前方（`idle_ground`）。旁白：「他不覺得痛，只是呆呆望著前方。」
3. 旁白：「他身上的光一點一點熄滅了。」同時：身上光點熄滅（`extinguish(2.0)`）、宮殿最後一組假光淡出、場景到最暗（`set_darkness(3, true)`）。
4. 他靜靜倒下（`collapse`）。奇瑪瑪特在寶座旁變黑、倒下（`collapse`）、淡出。旁白：「七金剛鸚鵡死了。他的妻子奇瑪瑪特也隨之死去。」
5. 老人走到他身邊、彎腰撿起（`pick`），手上帶著幾顆小金光走出畫面左側。旁白：「兩位老人帶走了他的珠寶。」
6. 黑邊收起；接著照舊顯示 `awaken` 文字卡（c2c 再改）。
- 第 3 段設局時，遊戲模式**不在演出前**套用 `_apply_lights(true)`（現在設局那一刻就會變暗）；改由演出第 3 步淡出、`end_state` 直接套用（跳過時直接到最暗）。原型模式照舊。
- 演出期間真正的老夫婦用 `cs.hide` 藏起（換牙、死亡都是），由替身演。
- 結束狀態：`lights_removed = 3`、場景最暗、真正的 Boss 藏起（`deactivate(true)`）、宮殿地上有他倒下的身體、奇瑪瑪特不在、老夫婦不在入口端（`couple_static = false`）。

### 死後的宮殿（`scenery_view`）

- `set_dead(on)`：地上顯示他倒下的身體（Seven Macaw 骨架擺 `collapse` 最後一格、失明的頭、顏色 ×0.5，位置 `STAGE_X`、面向左；沒有判定）；奇瑪瑪特隱藏。
- 由進度決定：死亡演出的 `end_state` 設 `true`；之後 `_apply_loadout()` 依 `awakened` 設定（覺醒後一直在）。讀檔後的宮殿狀態屬於 c2c 的通關存檔，不在本規格。

### 新動作（AI 寫成動作資料，不需要新美術）

| 角色 | 動作 | 用在 |
|---|---|---|
| Seven Macaw | `bow`（伏低到頭貼近地面、停住，單次）、`collapse`（側倒、停住，單次） | 換牙、死亡；死後擺設 |
| 兩位老人（各自的動作檔） | `reach`（雙手往前上方伸、停住，單次）、`pick`（彎腰撿起後直起，單次） | 換牙、死亡 |
| 奇瑪瑪特 | `collapse`（倒下、停住，單次） | 死亡 |

- 照現有動作檔格式與 12 fps；關節覆蓋、翅膀收著（非拍翅動作 `wing_arm ≥ −8`）等既有規則照舊；骨盆／根骨頭下沉量以量腳底的方式校準（同 c2a）。

### 不做

- `awaken`、`clear` 文字卡；取回手臂、覺醒閃回、出口、結尾、通關後存檔（c2c）。
- 聲音、新美術、鏡頭移動；戰鬥數值、判定、重試規則（牙痛開場只在第一次；換牙不重播）。
- 原型模式：照舊文字卡。

## 自測（加到 `game/tests/test_cutscene.gd`）

1. 機制：`together` 等全部做完才 return、跳過時立刻 return；`run()` 重入時不重跑；HUD 不在演出時不被寫；`end_state` 藏起的節點在交還後仍是藏著；`cs.hide` 的節點交還後恢復。
2. 遊戲模式第一次進宮殿播牙痛開場、`palace_card_seen`；重試不播；原型模式照舊卡片。
3. 每段演出：看完與跳過的結束狀態相同（玩家位置、Boss 狀態與顯示、`phase`、`lights_removed`、場景暗度、宮殿假光、死後擺設、奇瑪瑪特、老夫婦）。
4. 台詞與原卡一致（每句都出現在對應卡片裡）。
5. 死亡：「光熄滅」那句開始時宮殿最後一組假光仍亮著、演出結束時為 0；身上光點全熄。
6. 死後：`awakened` 時宮殿地上有身體、奇瑪瑪特隱藏；`start_at(4)` 也一樣；第 2、3 段沒有。
7. 新動作存在、單次／循環正確；關節覆蓋與既有規則測試照過。
8. `--cutscene` 接受 `toothache`、`teeth`、`death`。
9. 全套自測照舊全過（目前 400 項＋新增），沒有 `SCRIPT ERROR`／`Parse Error`／`flushing queries`。

## 風險與退路

| 風險 | 退路 |
|---|---|
| 伏低時老人擋不住嘴或眼睛 | 調 `bow` 的低頭角度與老人站位；仍不行就在「換頭」那一格讓老人往前一步 |
| AI 寫的倒下動作不自然（大型鳥側倒） | 影片抽格修正；備案：伏低後淡暗、不做側倒 |
| 死亡演出偏長（約 20 秒） | 可長按跳過；自動換句的係數可調 |
| 死後擺設和真正 Boss 同時出現 | 交還順序修正後 `end_state` 才藏起 Boss；測試 3 比對顯示狀態 |
